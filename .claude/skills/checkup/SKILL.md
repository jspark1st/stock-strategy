# 전면 점검 (정기 감사)

과거 두 차례 대점검에서 실제 결함이 나왔던 5개 축을 다시 훑는다. 목표는 코드 미화가 아니라 **정확 수치·논리 일관성**.

## 축 1 — 자동화 안전성
- 거래일 판정: 요일/달력 하드코딩 없이 독립소스 3중 교차확인, 휴장이면 무산출·무배포.
- cron 러너: flock(중복실행 방지)·파이프라인 실패 시 배포 중단·`git pull --rebase`·로그 로테이션.
- `auto_update=false`(.env)면 예약 건너뛰기.

## 축 2 — 논리 정합성 (모순·버그)
- **뉴스 이중계상**: 국내 시황 기사를 재료로 세면 가격움직임 재계상. `kind`/`scope`로 점수엔 재료·시장만.
- **게이트 우선 사이징**: '위험' 등급이면 권장비중 0% 강제, `position_scale`을 Kelly에 곱함.
- **결측 vs 제외**: 동시호가는 제외(재배분), 결측 아님. flow 결측=2.
- **채점 정합성**: 확정 일봉으로만 채점, 밀린 날짜 소급, 숏 도달판정 대칭.
- p_up 미산출을 '하락 100%'로 표시하지 않음.

## 축 3 — 팩트 기반 점수화
- **정확 수치는 API에서만.** LLM 숫자·뉴스 수치 본문 금지.
- 수급 무결성: 거래일 일치 검증, 전일 수급 대체금지, 확정없으면 provisional.
- 거래량 편향: 15:00 누적 → 완성계수 환산(자가학습 + ETF 부트스트랩).
- 뉴스 태깅: 제목 기준 순(net) 카운트(부정어 하나로 뒤집힘 방지).
- 미수집을 0으로 위장 안 함('미수집' 표기).
- SoT(`guide_docs/sample/…/scoring-close.md`) 대조: 가중치·클립·게이트 일치, 분기는 문서화.

## 축 4 — 데이터 신뢰도
- LS 스로틀/토큰만료/IGW00201 백오프, 네이버 항등식(합=0), Tavily published_date 팩트체크.
- 알려진 갭: 지수 거래대금 20일 이력, 야간/미국선물 정량치, 동시호가 확정치.

## 축 5 — 리포트/UI 품질
- 데이터 기준 스트립(기준시각·장중여부·출처·환율), 상태 배지 3종.
- ATR 손절/목표 색 = 진입가 대비 위치(숏에서 뒤집히지 않음).
- 한국 색관례(빨강 상승·파랑 하락), dataviz 스킬 팔레트 PASS, 라이트/다크 검증.

## 방법
1. `git diff`(최근 변경) + 대상 소스 정독. 필요시 `scoring-auditor` / `data-collector-debug` 서브에이전트에 위임.
2. 각 축을 코드에서 검증하고 산식은 직접 계산.
3. `.venv/bin/python -m pytest tests/ -q`(212, 2026-08-22) 통과 확인.
4. 발견을 **심각도 순 · 파일:라인 · 실패 시나리오** 로 정리.

## 출력
축별 결과와 발견 목록. 수정이 필요하면 제안하고 **사용자 승인 후** 진행. 회귀 테스트를 새 결함마다 추가하는 것을 원칙으로.
