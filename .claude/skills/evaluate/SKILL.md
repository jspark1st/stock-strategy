# 시스템 평가 (점수표)

버그를 나열하는 `/checkup` 이 아니다. **같은 자(evaluation6 12항목)로 오늘 점수를 다시 매긴다.**

## 위임

바로 **`system-evaluator`** 에이전트에 맡긴다. 이 스킬은 호출 조건만 고정한다.

- 기본: 라이브 DB·로그·pytest로 채점 + 제안. 코드 수정 없음.
- 사용자가 "전면"을 붙이면 평가 에이전트가 `pipeline-fanout-auditor` 도 띄운다.
- 사용자가 "문서로 남겨"라고 하기 전에는 `guide_docs/source/` 에 쓰지 않는다.

## 하지 말 것

- 항목 2(방향 예측력)를 n<40 적중률이나 close→close 로 부풀리기
- 백업·문서 개선을 "예측이 좋아졌다"고 말하기
- BTC 게이트 완화, vol_tilt 복원, 미국선물·news 가중 재주입을 기본 제안으로 넣기
- `.env` 값 출력
