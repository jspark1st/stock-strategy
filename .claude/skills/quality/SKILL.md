# 논리 버그 + 코드 품질 (찾아 고친다)

`/checkup` 은 보고만 한다. 이 스킬은 **`quality-fanout` 에이전트에 위임**해 확정 결함을 패치한다.

## 위임

바로 **`quality-fanout`**. 찾기 단계는 병렬(논리 8축 + 무성실패·죽은코드·가드·테스트공백).
고치기 전에 적대 검증. 결함마다 회귀 테스트.

## 자동 패치 / 보고만

- **패치:** 게이트 누출, 학습 `pass`, 결측→0 위장, 죽은 호출, 0나누기, 빠진 pytest
- **보고만:** 가중·캘리브 클램프·게이트 임계, BTC, UI 폴리쉬, 문서만의 문제
