# 개장 전 재확인 리포트

전일 마감 스코어를 **앵커**로 두고 간밤 정보(미국장 마감·야간선물·원달러)로 재확인하는 회차. cron: 평일 08:00 KST(`auto_preopen.sh`).

## 절차

1. **실행**
   ```bash
   python3 scripts/run_preopen.py
   ```
   → `out/preopen_<date>.json` 저장, 같은 날 마감 회차가 있으면 대시보드에 합쳐 4뷰.

2. **앵커 신선도 검증** (가장 중요) — 참조하는 전일 마감 앵커가:
   - **실제 직전 거래일** 것인지(휴장 건너뛰기 반영). 오래된 앵커면 재확인이 무의미.
   - 앵커의 `total`/`grade`/`p_up_raw`(캘리브레이션 전) 보존 여부.

3. **간밤 반영 확인**
   - 미국장 마감·야간/미국선물·원달러(`naver.usdkrw`)가 **재료(선행정보)** 로 반영됐는지.
   - 해외마감 기사는 익일 선행이라 재료 유지, 국내 시황 재계상은 없어야 함.

4. **검증**
   - `python3 -m pytest tests/ -q` 통과.
   - 개장전 체크리스트 뷰가 렌더되는지, 상태 배지가 '개장전 재검토'인지.

## 보고
앵커 기준일·신선도, 간밤 반영 항목, 재확인 결론(앵커 대비 상향/하향/유지), 이상치. 배포는 마감 스킬과 동일하게 명시 요청 시에만.
