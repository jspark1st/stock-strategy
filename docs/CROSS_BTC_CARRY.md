# cross/btc-carry — 주식↔크립토 교차 아이디어 구현

> **브랜치 전용.** main(오버나이트 롱 단일 전략)에는 병합하지 않는다 — 북극성 보존.
> 이건 두 트랙(overnight_report 주식 · hyodobot 크립토)의 **강점 결합** 실험이다.

## 아이디어 (왜 이걸 만들었나)

2026-08-25 대화에서 도출: 지표(RSI/MACD/EMA…) 최적화는 일봉·1시간봉·임계값·역추세 어디서도
**비용 후 OOS 알파가 없었다**(곡선맞춤). 재료(OHLCV)가 이미 가격에 반영돼서다. 반면 **차트 밖
구조**인 **펀딩 캐리**는 유일하게 (+)이고 **시장중립**이었다.

- **주식 트랙이 준 것(규율):** walk-forward·비용차감·저회전·정직한 성적(n<40 측정중)·구조>지표.
- **크립토 트랙이 준 것(실행부):** hyodobot의 24/7 주문·리스크·잔고검증·거래소 연동.
- **결합:** 주식의 *구조적 프리미엄 수취 insight* → 크립토의 *펀딩 캐리* 에 적용, hyodobot 실행부가 집행.

## 구성

| 파일 | 역할 |
|---|---|
| `src/collectors/binance_funding.py` | 펀딩레이트 이력 + 프리미엄지수(베이시스) 수집(무료·키불요·fail-safe) |
| `src/btc_carry.py` | 순수 함수: `carry_backtest`(비용차감 성적) · `carry_signal`(효도봇 소비용 신호) |
| `scripts/run_btc_carry.py` | 라이브 수집→정직 성적 출력 + `out/btc_carry.json`(효도봇 실행부 입력) |
| `tests/test_btc_carry.py` | 부호·비용·정직규율 회귀 |

## 전략 (시장중립 — 방향 예측 아님)

펀딩 양수 = 롱이 숏에게 지급 → **숏 무기한선물 + 롱 현물**(델타중립)이 8시간마다 수취.
방향을 안 맞혀도 되는 **구조적 수익**이라 견고하다(지표처럼 곡선맞춤 아님).

## 라이브 실측 (2026-08, ~0.46년, 단일레짐)

- 패시브(항상 중립) 순 **연환산 ≈ +2.3%** · 방향위험 0 · 펀딩 양수 72%
- 능동("양수일 때만") **−14.8%** — 회전 비용에 죽음(→ **저회전 패시브가 옳다**, 주식 교훈과 동일)

**정직한 한계:** 작다(예금 수준). 단일레짐·펀딩 낮은 구간. 불장선 커지고 하락장선 압축/역전.
자본 2배 묶임·청산·베이시스 리스크. **다레짐 재검증 전 레버리지·실거래 확대 금지.**

## 효도봇 연동(다음 단계, 미구현)

`run_btc_carry.py --json out/btc_carry.json` → `signal.position` 을 효도봇 실행부가 읽어
중립 포지션(숏 perp + 롱 spot)을 집행. **여기까지는 신호 산출(L0/L1), 실주문 없음.**
효도봇 백테스트에 **비용 모델 + walk-forward** 가 없으므로(현재 gross·K-Fold), 실거래 전
이 규율로 재검증 필요.
