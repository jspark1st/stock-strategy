- 작성일: 2026-08-18
- 상태: MVP 진행 중 (스캐폴딩·렌더러 완료 / 스코어링·수집기 대기)
- 산출물 성격: 개인용 도구. **투자 판단의 참고 자료이며 투자 권유가 아님.**

## 1. 배경과 의도

`perpelexity-finance-skills`에 만들어 둔 두 개의 Perplexity 스킬 —
**`market-close-review`**(장 마감 점수화·복기·종가베팅)와
**`market-open-sentiment`**(익일 아침 재평가) — 에 **설계 로직은 이미 완성**되어 있다.
이 프로젝트는 그 설계를 **실제로 돌아가는 실행 시스템**으로 옮기는 것이다.

핵심 차이: Perplexity의 `finance` 커넥터에 의존하던 시세 수집을
**LS증권 Open API(원천 데이터) + Tavily(뉴스 검색)** 로 대체한다.
스킬의 대원칙대로, **정확한 수치는 LLM이 아니라 증권사 API가 담당**한다.

## 1-α. 방향 개정 (2026-08-18) — 이 블록이 아래 "마감 후 1회 배치" 전제를 상위에서 재정의한다

사용자 확정 북극성:
- **실시간이 코어 (하이브리드 수집)**: 결정 시점(마감 전·개장 전·장중 관찰) 근처엔 LS **웹소켓 실시간** 체결/현재가, 과거 **멀티 타임프레임 캔들은 REST**. EOD 1회 배치는 시작점일 뿐 목표가 아니다.
- **주축 산출물 = 하루 2회 리포트**: ① **마감장 전**(~15시대, 오늘 대응 판단, `preclose` 성격) ② **다음날 개장 전**(아침 재평가, `market-open-sentiment` 성격). 기존 "마감 후 복기"는 배경/기록으로 물러난다.
- **시간축 확장**: 단타(현재) → **스윙** → **장기** 관점 보고서. 6팩터 코어는 재사용하되 호라이즌별 신호기간·가중치·게이트를 다르게 둔 변형.
- **단타 = 멀티 타임프레임(MTF) 필수**: 일봉 단일 금지. LS가 제공하는 분봉/시간봉(1H·4H 등)/일봉을 **최대한 많이·길게** 받아 TF 간 추세정렬·지지저항·모멘텀 컨플루언스로 분석.
- **정확도 반복개선**: 브라이어 채점·가중치 재적합 캘리브레이션을 1급 목표로.

## 2. 목적 (무엇을 만드나)

매일 **장 마감 후**, 다음을 한 번에 산출한다.

1. 한국 시장(KOSPI/KOSDAQ)을 6개 항목으로 **점수화** → 마감 총점(0~100)
2. **익일 상승 확률 / 하락 확률**
3. 게이트가 허용하는 만큼의 **익일 관심종목** (타점·손절·목표·무효화 + ATR/켈리 사이징)
4. 위 전부를 담은 **단일 HTML 리포트**

향후 확장(로드맵): 아침 재평가(승인/축소/취소), 매매 복기·브라이어 채점, 종가베팅 파이프라인, 자동 발송.

## 5. 점수 체계 (구현 대상 요약)

원본 공식의 SoT(Source of Truth)는
`perpelexity-finance-skills/market-close-review/references/scoring-close.md`.
이 프로젝트의 `src/scoring.py`는 그 공식을 **그대로** 구현한다.

- **6개 서브스코어(각 0~100)와 가중치**: 종가강도 0.20 · 시장폭 0.20 · 투자주체수급 0.25 · 거래대금 0.15 · 마감동시호가 0.10 · 마감후재료 0.10
- **총점** = Σ(가중치 × 서브스코어)
- **익일 확률**: `p_up = 1/(1+exp(-(total-55)/10))`, clip **0.20~0.80**
- **등급**: 75+ 강세 / 65~74 우호 / 55~64 중립 / 45~54 약세 / <45 위험
- **게이트**: <45 진입차단 / 45~54 후보1·비중50% / 55~74 후보2 / 75+ 후보3
- **결측 처리**: 항목 1개 결측 → 가중치 재배분, 수급(0.25) 결측은 2개로 취급, 2개↑ 결측 → 점수 미산출
- **`scores.phase`**: `close`(구현 대상) / `preclose_1430` · `preclose_1515`(종가베팅용, 추후) / `morning`(아침 재평가, 추후)

## 6. 산출물 — HTML 리포트 구성

`market-close-review` SKILL.md의 "출력 형식" 9블록을 따른다 (일부는 추후 단계).

1. 한 줄 결론  2. 마감 총점 / 익일 상승·하락 확률  3. **항목별 점수표**  4. 아침 점수 채점(추후)
5. 투자주체 수급  6. 익일 관심종목(타점·손절·목표·무효화·edge·켈리)  7. 주의 신호  8. 주요 재료  9. 면책

디자인은 스킬의 `assets/dashboard-template.html` 언어(teal 계열, 다크/라이트)를 계승.

## 9. 리스크 · 주의사항

- **LS 토큰은 익일 07:00 KST 고정 만료**(KIS의 24h 슬라이딩과 다름) → 만료 시각 기준 캐싱·재발급 로직 필수.
- **투자자별 수급은 잠정/확정 구분.** 15:45 잠정 → 18:00 확정. 잠정치로 낸 점수엔 "잠정" 배지, 확정 후 재계산.
- **데이터 재배포 제한.** 외부 공개 대시보드에 LS 원천 시세를 그대로 노출하지 않는다. 개인용 한정.
- **시크릿은 `.env`에만.** git 커밋 금지, 프론트/로그 노출 금지, 값은 스크립트가 `os.environ`으로만 읽는다.
- **규제 변경 날짜 반영**: 2026-09-14부터 KRX 애프터마켓(16:00~20:00)·정적 VI(±10%) 신설, KRX 시간외 단일가 폐지. 종가베팅 단계 구현 시 반영.
- **첫 20거래일은 일부 항목 결측**(거래대금 20일 평균, preclose 시간정규화 분모). 결측 처리 로직으로 흡수.
- **가격제한폭(±30%)** 때문에 ATR 손절이 무력화될 수 있음 — 오버나이트 포지션은 overnight-guard와 함께.
