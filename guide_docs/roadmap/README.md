# roadmap — 다음에 무엇을 하는가

최종 목표: 오버나이트 롱 **매매 자동화**. 지금은 검증. 승격은 비용 차감 순손익으로만 한다.

CLAUDE.md 하단 「이어서 할 곳」의 **현재 정본은 이 파일**이다. 로그는 이력, 여기는 우선순위.

---

## 로드맵 L0 → L4

| 단계 | 내용 | 상태 (2026-08-30) |
|---|---|---|
| **L0** | 리포트만 생성 | ✅ 크론 3회차 + 사이트 |
| **L1** | Paper 가상 체결·비용 차감 | ⚠️ 배선됨. 게이트 수정(08-28) 후 표본 축적 시작. **n 작으면 침묵** |
| **L2** | 주문 후보 → 사람 승인 | L1 순손익 실증 후 |
| **L3** | 조건부 자동 주문 | 검증 후 |
| **L4** | 자동 진입·청산 | 충분한 실증 후 |

하드 게이트(상위 단계 무조건 차단): `risk=위험 · data=잠정 · confidence<임계 · event_lock`.
통과율을 올리려고 임계를 낮추지 않는다.

**L0~L4 = 단기 오버나이트 트랙 하나를 검증·자동화 끝까지.** 이게 "1트랙을 제대로"의 레퍼런스다.

## L5+ — 보고서 유형 확장 (장기 비전 · AGENTS.md 「장기 비전」)

> 목적: AI 발전에 따라 예측 보고서 지속 강화 → 중장기·종합 금융 보고서. **지금 락(단일 전략)은 유지.**
> 확장은 넓이가 아니라 **독립 트랙**(BTC 패턴). 각자 하네스·성공척도·검증. measure-first 로만 승격.

| 단계 | 내용 | 전제 |
|---|---|---|
| **L5** | 중장기 트랙(주간·월간 방향) = 다른 라벨·하네스·캘리브, 오버나이트 코드 재사용하되 독립 | 단기 트랙 L2+ 실증 · 다레짐 표본 |
| **L6** | 종합 금융 보고서 = **검증된 트랙들의 집계·서술**(새 예측 생성 아님, LLM 서술 확장) | 2+ 트랙이 measure-first 통과 |

**착수 전제(어길 시 과거 실패 재현):** ①기존 트랙에 안 섞음 ②measure-first 후 승격 ③LLM 은 예측
수치 생성 금지(서술·비평·리서치만) ④검증 안 된 엣지 표시 금지. **깊이(검증) 없이 넓이부터 늘리지 않는다.**
지금은 착수 아님 — 단기 트랙 실증·다레짐 데이터가 먼저.

## 지금 우선순위

### P0 — 관측만, 코딩 금지에 가깝다

0-A. **신 게이트 통과분의 paper 손익 축적.** 구 게이트 0/18 → 신 3/18. L2 판단은 비용 후 순손익.
     현재 소표본으로 「된다/안 된다」를 말하지 말 것. `store.gate_stats()` · 연속 10회 0 경보.

0-B. **KOSDAQ 캘리브 원시 기울기 음(−0.0106).** 실거래 지평에서 총점이 역방향. 하한 클램프가 가림.
     다음 재적합에서도 유지되면 총점 구성 재검토. 월간 `auto_revalidate` 가 관측.
     상세 [`../source/evaluation6.md`](../source/evaluation6.md).

### P1 — 다레짐이 쌓인 뒤에만 손댄다

0. **방향 판별(AUC).** 마감 캘리브는 비관편향만 고쳤고 판별은 거의 동전.
   - ⓐ 하락/횡보 표본 후 `exp_calibrate.py` / 간밤 틸트 재측정. 2026 상반기 상승레짐 숫자를 일반화 금지.
   - ⓑ KOSPI **마감** 판별은 미해결(종가 피처 OOS≈0.50). 간밤은 개장전에만 유효.
   - ⓒ 라이브 채점 N≥40 이면 `fit_calibrator` 가 부트스트랩을 대체.

vol_tilt 는 이미 철회됨. 구 라벨(종가→종가) 이득을 이유로 되돌리지 말 것.

### P2 — 인프라 잔여 (코딩 가능, 예측력을 안 올림)

- 거래량 완성계수: `intraday_volume` 표본이 충분하면 기본값 0.93/0.96 → 학습치. 표기 확인.
- t1601 suffix: `probe_investor_map.py` conf≥0.95 일 때만 네이버→LS 이전 **결정**. 추측 매핑 금지.
- 데이터 갭: 거래대금 20일 · 야간선물 % · 동시호가 확정 — 소스 확보 전 구현 금지.
- 사용자: `.env` `backup_remote=…` (오프박스). Vercel `view_password` · `auth_token`.
