# 고수 벤치마킹 플레이북 — 오전 단타 실전 규칙

국내 전업 단타 트레이더와 해외 갭앤고(Gap and Go) 트레이더의 공통 루틴을 정리한 것.
스코어링 엔진의 종목 필터·타점 판정 로직은 이 문서를 기준으로 구현한다.

---

## 0. 공통 대전제

- **하루 시세의 절반 이상은 09:00~09:30에 결정된다.** 시초가 30분에 체결강도·호가잔량·초반 시세로 진입 여부를 판단한다 ([단타매매 정리](https://blue-rock.tistory.com/849)).
- **09:30 이후로 넘어가면 이길 확률이 떨어진다.** 15년 경력 트레이더는 "시초가 매매는 09:00~09:30에 끝낸다, 9시 반 넘어가면 내려갈 확률이 더 높다"고 명시한다 ([시초가 매매 특강](https://www.youtube.com/watch?v=K1mFmqHgYv4)).
- **뉴스는 필터, 진입 판단은 수급.** "뉴스가 뜨고 나면 이미 늦는 경우가 많다. 차트 움직임·거래량·호가창 잔량에 더 집중" ([단타 노하우 총정리](https://lunablossom.tistory.com/entry/%EC%A3%BC%EC%8B%9D-%EB%8B%A8%ED%83%80-%ED%95%98%EB%8A%94-%EB%B0%A9%EB%B2%95-%EB%A7%A4%EB%A7%A4-%EA%B8%B0%EB%B2%95-%EB%85%B8%ED%95%98%EC%9A%B0-%EC%B4%9D%EC%A0%95%EB%A6%AC)).
- **추격매수 금지가 1원칙.** 갭 이후 바로 사는 건 도박에 가깝고, 되돌림 후 재돌파 지점이 정석 타점 ([시가 돌파 매매](https://www.youtube.com/watch?v=N1K88vGeaZI)).

## 1. 전일(D-1) 준비 — 고수는 전날부터 후보를 만든다

시초가 매매는 아침에만 준비하는 게 아니라 **전일부터 후보군 10종목 내외를 뽑아둔다** ([시초가 매매 특강](https://www.youtube.com/watch?v=K1mFmqHgYv4)).

| 항목 | 기준 |
|---|---|
| 관심종목 수 | 10~15종목 이내로 압축 ([직장인 단타 루틴](https://leopardwealth.com/entry/%EC%A7%81%EC%9E%A5%EC%9D%B8-%EB%8B%A8%ED%83%80%EC%A1%B1%EC%9D%84-%EC%9C%84%ED%95%9C-%EC%99%84%EB%B2%BD%ED%95%9C-%EB%A7%A4%EB%A7%A4-%EB%A3%A8%ED%8B%B4-%EA%B0%80%EC%9D%B4%EB%93%9C-%EC%84%B1%EA%B3%B5%ED%95%98%EB%8A%94-%ED%8A%B8%EB%A0%88%EC%9D%B4%EB%8D%94%EC%9D%98-%EB%B9%84%EB%B0%80)) |
| 선정 소스 | 당일 거래대금 상위, 거래량 급증, 장대양봉, 상한가, 신고가 |
| 재료 확인 | 증권사 뉴스창 "특징주" 검색, 공시(DART) 원문 확인 |
| 사전 기록 | 종목별 **시초가 진입 조건 / 눌림 진입 조건 / 손절 라인 / 목표가**를 미리 적어둠 ([갭 상승 타이밍](https://hiiinformation.com/43)) |
| 시간외 체크 | 16:00~18:00 시간외 단일가 변동성이 크면 다음날 갭 발생 확률↑ ([장초반 매매](https://blog.naver.com/nolbu3990/222692291450)) |

**주의**: 시간외 상한가 종목의 다음날 시초가는 오히려 매도 자리인 경우가 많다. 추격매수 금지 ([시간외 상한가 다음날](https://play-in-stock.tistory.com/911)).

## 2. 아침 루틴 (07:30~09:00)

고수들이 공통적으로 하는 행동 ([단타 고수 전략](https://toxicity.tistory.com/entry/%EC%A3%BC%EC%8B%9D%EB%8B%A8%ED%83%80-%EA%B3%A0%EC%88%98%EB%93%A4%EC%9D%98-%EC%A0%84%EB%9E%B5-%EB%8B%A8%EC%88%9C%ED%95%9C-%EA%B8%B0%EC%88%A0%EC%9D%B4-%EC%95%84%EB%8B%8C-%EB%B0%98%EB%B3%B5%EC%9D%98-%EB%AF%B8%ED%95%99)):

## 4. 타점 3종 — 갭 이후 무엇을 보는가

### 4-1. 시가 눌림 매매 (가장 안전)
갭 후 차익물량이 쏟아져 하락 → **일봉상 최근 3개월 내 의미 있는 가격**(전고점, 매물대, 5/20일선)에서 지지 확인 후 매수 ([시초가 갭상승 매매법](https://www.youtube.com/watch?v=Tm7G-MA0Upg)).
- 3개월 넘은 지점은 의미 있는 가격으로 보지 않는다.
- 지지선 이탈 시 칼같이 손절.

### 4-2. 시가 돌파 매매
눌림 후 반등해 **시초가 또는 일봉상 저항선을 거래량 동반해 돌파할 때** 진입 ([시가 돌파 매매](https://www.youtube.com/watch?v=N1K88vGeaZI)).
- 3분봉 첫 장대양봉이 **완성된 것을 확인하고** 진입. 진행 중인 봉에 올라타지 않는다.
- 가짜 돌파(거래량 없이 살짝 넘었다 빠짐) 주의.

### 4-3. 무조정 급등 (추세 추종)
갭 후 조정 없이 장대양봉 연속 → 돌파 매매로 접근하되 **비중 10% 이내, 손실 5% 각오** ([시초가 갭상승 매매법](https://www.youtube.com/watch?v=Tm7G-MA0Upg)).

### 진입 금지 신호
- 첫 3분봉이 긴 윗꼬리 또는 음봉
- 시초가 이후 거래량 급감
- **시초가 이탈 + 전일 종가까지 이탈** (전일 종가는 마지노선) ([갭상승 매매 노하우](https://www.youtube.com/watch?v=w4VOz0u7lwY))
- 갭상승 장대음봉 출현
- 이슈가 이미 끝난 테마주

## 5. 체결강도 활용 (수급 판정의 핵심)

- 체결강도 = 매수체결량 / 매도체결량 × 100. 실거래 기반이라 **속이기 어려운 지표** ([체결강도+거래대금](https://www.youtube.com/watch?v=UDk69yuv0sE)).
- **단순히 100 초과가 아니라, 5분 체결강도가 20분 체결강도를 3~5% 이상 차이로 상향 돌파(골든크로스)할 때가 타점.** 단 둘 다 100 이상일 것. 20분 데이터가 필요하므로 09:20 이후 적용.
- 체결강도 140~150 이상이 **3분 이상 지속**되어야 유효. 단발성 급등은 미끼일 수 있다 ([체결강도 150 이상](https://zezemini.tistory.com/entry/%EC%B2%B4%EA%B2%B0-%EA%B0%95%EB%8F%84-150-%EC%9D%B4%EC%83%81-%EC%A1%B0%EA%B1%B4-%EA%B2%80%EC%83%89%EC%8B%9D%EA%B3%BC-%ED%95%A8%EA%BB%98-%EC%93%B0%EB%A9%B4-%EC%83%9D%EA%B8%B0%EB%8A%94-%EB%B3%80%ED%99%94)).
- 회피: 체결강도 급락 후 재상승 없음, 거래대금 20억 이하.

**엔진 구현**: `flow_score`에 5분/20분 체결강도 골든크로스 발생 여부를 불리언 보너스(+10)로 반영하고, 체결강도 지속시간(초)을 함께 저장한다.

## 6. 리스크 규칙 — 여기서 승패가 갈린다

| 항목 | 고수 기준 |
|---|---|
| 손절 | -1.5% ~ -2% 고정 자동 손절. 시초가·지지선 이탈 시 즉시. **당일 청산이 아니라 하루 이상 보유할 후보라면 고정 %가 아니라 일봉 ATR(14)×배수로 산정** — `references/atr-risk-sizing.md` |
| 익절 | 1~3% 또는 3~5%에서 분할. "많이 먹으려다 -10% 간다" |
| 손익비 | 익절 3%면 손절은 1.5~2%. 익절 > 손절 구조 필수 ([나무위키 단타매매 기법](https://namu.wiki/w/%EC%A3%BC%EC%8B%9D%ED%88%AC%EC%9E%90/%EB%8B%A8%ED%83%80%EB%A7%A4%EB%A7%A4%20%EA%B8%B0%EB%B2%95)). ATR 기반 손익비(b)를 구했으면 `p_breakeven=1/(1+b)`와 `p_up/p_down`을 비교해 기대값(edge)이 양수인지 반드시 확인 — 음수면 익절 목표가 아무리 좋아도 진입하지 않는다 |
| 타임 스톱 | 15분 내 +2% 안 나오면 모멘텀 소진, 청산 ([Gap and Go](https://tickerdaily.com/learn/day-trading/gap-and-go)) |
| 매매 횟수 | 하루 1~2회 집중. 종목당 1파동만 먹고 종료 |
| 비중 | 몰빵 금지, 분할 매수·분할 매도 |
| 물타기 | 원칙적으로 금지. 하려면 -3%/-6% 단계와 -8% 최종 손절을 사전에 확정 |
| 종료 시각 | 09:30 마감이 원칙, 늦어도 10:30 |
| 복기 | 매매일지 필수 — "왜 샀는지 / 왜 그 자리였는지 / 왜 손절했는지" |

## 7. 시장 국면 필터 (이게 없으면 다 무의미)

갭앤고는 **강세장에서만 통한다**. 지수가 하락·횡보 국면이면 승률이 급락하므로 아예 쉬는 것이 정답 ([Gap and Go](https://tickerdaily.com/learn/day-trading/gap-and-go)).

엔진에 다음 게이트를 건다:

```
if 시장분위기_총점 < 45:      → 신규 진입 전면 차단 (알림만)
if 45 <= 총점 < 55:          → 후보 종목 수 최대 1개, 비중 50% 축소
if 총점 >= 75:               → 후보 3개까지, 정상 비중
```

## 9. HTS 조건검색식 기본형 (그대로 이식 가능)

```
1. 당일 거래량 > 전일 거래량 × 2
2. 당일 시가 > 전일 종가            (갭상승)
3. 현재가 > 시가                    (시초가 미이탈)
4. 전일 거래대금 100억 이상
5. 현재가 5일선 위 AND 전일 종가 5일선 위
6. 체결강도 100 이상
7. 전일 고가 돌파
8. 20/60/120 이평 상승추세
9. 거래대금 순위 당일 100위 이내
```
([주도주 포착 검색식](https://blog.naver.com/premier_stock/222877977647), [단타매매 정리](https://blue-rock.tistory.com/849))

분봉 기반 갭상승-눌림-재상승 포착 조건식 예시:
```
[일] 전일종가 대비 시가등락률 1% 이상
[3분] 첫분봉 시가대비 종가등락률 -1% 이하     (초반 눌림)
[1분] 첫봉 거래량 대비 현재 거래량 100% 이상  (거래량 재유입)
[3분] 첫봉 시가대비 종가등락률 0.5% 이상      (재상승 전환)
[1분] 거래대금 4억 이상
```
([갭상승 하락후 상승 매수타점](https://tensortrade.tistory.com/32))
