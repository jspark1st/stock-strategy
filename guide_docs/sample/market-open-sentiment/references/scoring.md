# 점수 공식과 확률 변환

## 1. 항목별 서브스코어 (각 0~100)

### 1) 장전 뉴스 강도 (가중치 0.25)
```
news_score = 50
           + 8 * (호재 재료 수 - 악재 재료 수)          # ±32 clamp
           + 10 * 섹터_확산도                            # 0~1, 재료가 걸친 섹터 비율
           + 10 * 대형주_관련도                          # 0~1
           - 15 * 선반영_플래그                          # 전일 이미 급등 시 1
clamp(0, 100)
```
재료 분류 키워드:
- 호재: 수주, 계약, 흑자전환, 어닝서프라이즈, 신제품, 승인, FDA, 자사주, 배당확대, 지수편입, 정책수혜
- 악재: 유상증자, 전환사채, 감자, 적자전환, 어닝쇼크, 소송, 리콜, 제재, 대주주매도, 지수제외

### 2) 시초가 갭 (0.20)
```
gap_pct = (시가 - 전일종가) / 전일종가 * 100
gap_score = 50 + 12.5 * clamp(gap_pct, -4, +4)
```
지수 기준으로 계산하되, 종목 점수는 해당 종목 갭으로 대체. 갭 +4% 초과는 과열로 보고 100이 아닌 85로 캡한다.

### 3) 동시호가 반응 (0.20)
```
bid_ratio = 매수잔량 / (매수잔량 + 매도잔량)
drift     = (08:59 예상체결 - 08:40 예상체결) / 08:40 예상체결 * 100
call_score = 50 + 60 * (bid_ratio - 0.5) + 8 * clamp(drift, -3, +3)
```

### 4) 장 초반 거래량 (0.20)
```
vol_mult = 09:00~09:05 거래량 / (20일 평균 09:00~09:05 거래량)
vol_score = 50 + 25 * log2(clamp(vol_mult, 0.25, 8))
```
거래량은 방향성이 없으므로, 갭 방향이 하락일 때 vol_score는 50 기준 반전시켜 적용한다.

### 5) 수급 강도 (0.15)
```
체결강도 = 매수체결량 / 매도체결량 * 100
flow_score = 50 + 0.25 * (체결강도 - 100)
           + 10 * 상위20종목_상승비율_초과분   # (비율 - 0.5) * 20
```
외국인·기관 순매수 추정치를 쓸 수 있으면 ±10점 보정.

추가 보너스(09:20 이후에만 적용):
```
if 5분_체결강도 > 20분_체결강도 * 1.03 and 둘 다 >= 100:  flow_score += 10
if 체결강도 >= 140 이 3분 이상 지속:                        flow_score += 5
clamp(0, 100)
```
단발성 체결강도 급등은 미끼일 수 있으므로 지속시간(초)을 반드시 함께 저장한다.

## 2. 종합 점수
```
total = 0.25*news + 0.20*gap + 0.20*call + 0.20*vol + 0.15*flow
```

## 3. 확률 변환
로지스틱 매핑으로 상승 확률을 구한다.
```
p_up = 1 / (1 + exp(-(total - 55) / 9))
p_down = 1 - p_up
```
- total 55 → 50%
- total 70 → 약 84%
- total 40 → 약 16%

과신 방지를 위해 상·하한을 15%~85%로 클리핑한다.

## 4. 등급 해석
| 총점 | 등급 | 대응 |
|---|---|---|
| 75+ | 강세 | 공격적 단타 가능, 비중 확대 |
| 65~74 | 우호 | 정상 진입, 종목 선별 |
| 55~64 | 중립 | 소액·선별 진입 |
| 45~54 | 약세 | 관망, 현금 비중 유지 |
| 45 미만 | 위험 | 신규 진입 금지 |

## 5. 캘리브레이션
- 매일 총점과 당일 지수 종가 방향(및 상승종목 비율)을 DB에 저장한다.
- 30거래일 이상 쌓이면 로지스틱 회귀로 가중치와 절편(55), 스케일(9)을 재적합한다.
- 브라이어 스코어(Brier score)로 확률 예측 품질을 추적한다. 0.25 미만이면 유의미.
- 신뢰구간이 확보되기 전에는 확률을 "참고 지표"로만 표기한다.

## 6. 데이터 결측 처리
- 항목 하나가 결측이면 해당 항목 가중치를 나머지에 비례 배분하고, 출력에 "부분 데이터" 배지를 표시한다.
- 2개 이상 결측이면 점수를 산출하지 않고 "데이터 부족"으로 표시한다.
