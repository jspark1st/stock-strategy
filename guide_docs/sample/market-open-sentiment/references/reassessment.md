# 전일 마감 판단 재평가 (지수 방향성 전용)

이 스킬은 이제 **독립적으로 새 시장분위기 점수를 내지 않는다.** `market-close-review`가 전일 마감에 확정한
지수 방향성 판단(마감 점수·p_up/p_down·등급·게이트 비중)을 입력으로 받아, 오늘 아침 데이터로
**승인(confirm) / 축소(reduce) / 취소(cancel)** 세 가지 중 하나로 재평가한다.

**재평가 대상은 지수(코스피/코스닥) 방향성뿐이다.** 개별 종목 후보(타점/손절/목표/무효화)는 여전히
`market-close-review`의 `references/review-playbook.md`가 전담한다. 이 스킬은 그 종목 후보들이
오늘 실행돼도 되는지를 결정하는 **상위 게이트**만 담당한다.

## 0. 데이터 연결 방식 (현재는 수동)

`market-close-review`와 이 스킬 사이에 결과를 자동으로 넘겨주는 저장소가 아직 없다.
**전일 마감 브리핑을 사용자가 채팅에 직접 붙여넣는 방식**으로 연결한다.

### 필요 입력 (사용자에게 요청할 붙여넣기 템플릿)

```
[전일 마감 요약]
마감 총점: __
마감 p_up / p_down: __ / __
마감 등급: __ (강세/우호/중립/약세/위험)
마감 게이트 결과: 후보 __개, 비중 __%
잠정치(provisional) 사용 여부: __
마감 후 공시·무효화 이슈: __ (유상증자/CB 등, 있으면 어떤 종목)
종가 베팅 진입 종목: __ (있으면 진입가·비중)
```

**이 입력이 없으면 재평가를 진행하지 않는다.** 대신 사용자에게 위 템플릿을 요청하거나,
"전일 market-close-review 브리핑을 붙여넣어 주세요"라고 먼저 물어본다.
데이터가 없다고 해서 독자적으로 새 점수를 만들어내지 않는다 — 그건 이 스킬의 역할이 아니다.

향후 자동화하려면 `market-close-review`가 마감 시 결과를 파일/DB(`scores` 테이블)에 적재하고,
이 스킬이 익일 07:30 실행 시 그 최신 row를 읽어오는 파이프라인으로 바꾼다
(`market-close-review/references/architecture-close.md`의 DB 스키마를 그대로 재사용).

## 1. 오늘 아침 자체 데이터 수집·점수화 (기존과 동일)

`references/scoring.md`의 5개 항목(장전 뉴스·시초가 갭·동시호가·장 초반 거래량·수급 강도)을
그대로 계산해 `open_score`와 `open_p_up`을 낸다. 이 값은 이제 최종 출력이 아니라
**재평가의 중간 입력값**이다.

## 2. 방향 일치 판정

```
close_direction = "상승" if close_p_up >= 0.5 else "하락"
open_direction  = "상승" if open_p_up  >= 0.5 else "하락"
direction_match = (close_direction == open_direction)
```

## 3. 최종 판정 로직 — 승인 / 축소 / 취소

우선순위 순서대로 평가한다. 위에서 조건이 걸리면 아래는 평가하지 않는다.

```
1. 마감 후 무효화 이슈 발생 (유상증자·CB·감자·대주주매도 공시)
   → 취소. 아침 데이터와 무관하게 해당 종목/포지션 즉시 제외.

2. 마감 게이트가 이미 <45로 신규 진입을 차단한 경우
   → 취소. 아침이 아무리 좋아도 마감 점수 자체가 위험 등급이면 신규 진입 안 한다.
   (market-close-review SKILL.md의 게이트 거부권 규칙과 동일)

3. direction_match == false (마감 방향과 아침 방향이 반대)
   → 취소. 마감이 상승을 예상했는데 아침 갭이 하락이거나, 그 반대인 경우.
   가장 흔한 실패 패턴이므로 반드시 코멘트에 "방향 불일치"라고 명시한다.

4. open_score < 45 (방향은 일치하나 아침 자체가 위험 등급)
   → 취소. 아침 국면 필터가 최우선이다 (market-open-sentiment 원래 게이트 원칙).

5. open_score 45~54 (방향 일치, 강도 약함)
   → 축소. 최종 비중 = 마감 게이트 비중 × 0.5.

6. open_score >= 55 (방향 일치, 강도 충분)
   → 승인. 최종 비중 = 마감 게이트 비중 그대로.
   open_score >= 75이면 "공격적 확인" 배지를 붙이되, 비중 상한(종목당 25%, 종가 베팅 10%)은 그대로 유지한다.
```

```
최종 비중 = min(마감 게이트 비중, 위 판정에서 나온 배수 적용값, 기존 상한)
```

## 4. 결합 확률 (참고 지표, 캘리브레이션용)

판정은 위 3장의 규칙 기반 로직으로 하되, 참고용으로 결합 확률도 함께 낸다.

```
p_up_final = 0.35 * close_p_up + 0.65 * open_p_up
```

가중치가 아침에 더 큰 이유: 시간적으로 더 가까운 정보가 강하다. 이 값은 브리핑에 표시하되,
**판정(승인/축소/취소)은 3장의 규칙이 우선**이고 `p_up_final`은 보조 참고치다.

## 5. 종가 베팅(오버나이트) 포지션이 있는 경우

전일 마감에 종가 베팅으로 이미 진입한 포지션이 있다면, 이 재평가는 신규 진입 여부가 아니라
**보유 지속 여부**를 판정한다. 판정 결과를 아래처럼 변환한다.

| 판정 | 종가 베팅 포지션 대응 |
|---|---|
| 승인 | 유지. `market-close-review/references/closing-bet-playbook.md`의 익일 시나리오 규칙대로 관리 |
| 축소 | 절반 청산, 나머지는 타임스톱(10:00)까지 관찰 |
| 취소 | 시초가 즉시 전량 청산 (갭하락 −3% 이하 규칙과 별개로, 방향 불일치만으로도 청산 트리거) |

## 6. 종목 후보 필터와의 연결

이 스킬의 판정 결과(승인/축소/취소 + 최종 비중)가 `market-open-sentiment` 자체 게이트를 대체한다.
SKILL.md의 "실전 게이트" 표는 이제 `open_score` 단독이 아니라 이 재평가 판정으로 후보 개수·비중을 정한다.

```
취소 → 신규 진입 차단, 관망 알림만
축소 → 후보 최대 1개, 비중 50% 축소
승인 (open_score 55~74) → 후보 최대 2개, 정상 비중
승인 (open_score 75 이상) → 후보 최대 3개, 공격적 대응 허용
```

`references/pro-playbook.md`의 3장 필터·4장 타점 규칙은 그대로 쓰되, 위 표가 허용하는 개수까지만
후보를 낸다.

## 7. 출력에 추가할 항목

기존 "종합 점수/상승확률/하락확률" 대신 아래를 낸다.

| 항목 | 값 |
|---|---|
| 전일 마감 총점 / p_up | (사용자 입력값) |
| 오늘 아침 점수(open_score) / p_up | (계산값) |
| 방향 일치 여부 | 일치 / 불일치 |
| **최종 판정** | 승인 / 축소 / 취소 |
| 최종 비중 | 마감 게이트 비중 × 배수 |
| 결합 확률(p_up_final) | 참고 지표 |
| 판정 근거 1줄 | 예: "마감 상승 기대(p_up 68%) vs 아침 갭 -1.2% 하락 → 방향 불일치로 취소" |

## 8. 리스크·주의사항

- **방향 불일치 취소 규칙이 가장 중요하다.** 마감 점수가 아무리 높아도 아침에 반대로 갈 수 있다 — 이게 이 재평가 스킬을 만든 이유다.
- 전일 마감 데이터를 사용자가 잘못 붙여넣거나 일부만 주면(예: p_up 없이 총점만) 판정이 부정확해진다. 누락된 필드는 반드시 "재평가 불가/부분 재평가"로 명시한다.
- 수동 붙여넣기 방식은 사용자가 매일 잊어버리면 재평가가 아예 실행되지 않는다. 반복 사용 시 자동화(파일/DB 연결)를 권장한다고 안내한다.
- 이 문서는 투자 판단의 참고 자료이며 투자 권유가 아니다.
