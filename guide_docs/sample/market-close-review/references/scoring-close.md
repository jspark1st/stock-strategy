# 마감 점수 공식과 익일 확률 변환

## 1. 항목별 서브스코어 (각 0~100)

### 1) 종가 강도 (가중치 0.20)
종가가 일중 어디에 찍혔는지가 등락률보다 중요하다. 고가 마감은 익일 갭상승 확률을 올린다.

```
close_pos = (종가 - 저가) / (고가 - 저가)          # 0~1, 고가-저가=0이면 0.5
chg_pct   = (종가 - 전일종가) / 전일종가 * 100

close_score = 50 + 40 * (close_pos - 0.5)          # ±20
            + 6 * clamp(chg_pct, -3, +3)           # ±18
            + 8 * 5일선_상회_플래그                # 종가가 5일 이평 위면 1, 아래면 -1
clamp(0, 100)
```

윗꼬리가 긴 음봉(close_pos < 0.3)은 등락률이 플러스여도 감점된다. 이게 의도한 동작이다.

### 2) 시장 폭 (0.20)
지수는 대형주 몇 개로 왜곡된다. 폭이 진짜 체력이다.

```
adv_ratio = 상승종목수 / (상승종목수 + 하락종목수)
limit_net = 상한가수 - 하한가수

breadth_score = 50 + 80 * (adv_ratio - 0.5)        # ±40
              + 2 * clamp(limit_net, -10, +10)     # ±20
clamp(0, 100)
```

**지수 등락률과 시장 폭의 괴리를 반드시 코멘트에 적는다.**
지수 +1%인데 adv_ratio가 0.4 이하면 "대형주 착시"로 표기하고 익일 확률을 5%p 하향한다.

### 3) 투자주체 수급 (0.25)
가장 무거운 항목이다. 외국인·기관이 실제로 돈을 넣었는지가 익일 연속성을 결정한다.

```
frn = 외국인 순매수 금액 (억원, 코스피+코스닥 합산)
ins = 기관 순매수 금액 (억원)
prg = 프로그램 순매수 금액 (억원)

flow_score = 50
           + 12 * clamp(frn / 3000, -2, +2)        # 3000억 = 1단위, ±24
           + 8  * clamp(ins / 3000, -2, +2)        # ±16
           + 5  * clamp(prg / 3000, -2, +2)        # ±10
           + 10 * 외국인_연속순매수_3일_플래그      # 3일 연속 순매수면 1, 3일 연속 순매도면 -1
clamp(0, 100)
```

**개인 순매수는 점수에 직접 반영하지 않는다.** 외국인·기관의 반대편일 뿐 독립 정보가 아니다.
다만 개인만 순매수인 날(frn < 0, ins < 0, 개인 > 0)은 `flow_score`에서 8점을 추가 차감한다.

**잠정치 주의**: 15:40 시점 값은 잠정치다. 확정치와 수백억 단위로 차이 날 수 있다. 잠정치를 썼으면 점수에 `provisional=true` 플래그를 붙이고, 18:00 확정치로 재계산한다.

### 4) 거래대금 (0.15)
```
amt_mult = 당일 거래대금 / 20일 평균 거래대금
amt_score = 50 + 30 * log2(clamp(amt_mult, 0.4, 4))
```
거래대금은 방향성이 없다. **`chg_pct < 0`이면 50 기준으로 반전**시켜 적용한다 (`amt_score = 100 - amt_score`).
대금 급증 + 하락 = 투매이므로 감점되어야 한다.

### 5) 마감 동시호가 (0.10)
```
call_drift = (종가 - 15:20 지수) / 15:20 지수 * 100
call_score = 50 + 25 * clamp(call_drift, -1, +1)
```
동시호가 10분에 지수가 위로 밀렸으면 기관 종가 매수, 아래로 밀렸으면 청산 물량이다.
지수 리밸런싱일·옵션만기일에는 이 항목을 **제외**하고 가중치를 나머지에 배분한다. 노이즈가 신호를 압도한다.

### 6) 마감 후 재료 (0.10)
```
news_score = 50
           + 10 * (호재 재료 수 - 악재 재료 수)     # ±30 clamp
           + 15 * clamp(야간선물_등락률, -1.5, +1.5) / 1.5   # ±15
           + 10 * clamp(미국선물_등락률, -1, +1)             # ±10
clamp(0, 100)
```
재료 분류 키워드:
- 호재: 수주, 계약, 흑자전환, 어닝서프라이즈, 신제품, 승인, FDA, 자사주매입, 배당확대, 지수편입, 정책수혜, 무상증자
- 악재: 유상증자, 전환사채, 감자, 적자전환, 어닝쇼크, 소송, 리콜, 제재, 대주주매도, 지수제외, 관리종목, 감사의견거절

**마감 후 유상증자·CB 공시는 단일 항목으로 −25점** 처리한다. 익일 갭하락 확률이 압도적으로 높다.

## 2. 종합 점수
```
total = 0.20*close + 0.20*breadth + 0.25*flow + 0.15*amt + 0.10*call + 0.10*news
```

## 3. 익일 확률 변환
```
p_up = 1 / (1 + exp(-(total - 55) / 10))
p_down = 1 - p_up
```
- total 55 → 50%
- total 70 → 약 82%
- total 40 → 약 18%

스케일이 아침 공식(9)보다 큰 10인 이유: **마감→익일 예측은 장중 예측보다 불확실성이 크다.** 오버나이트 갭 리스크가 끼어들기 때문에 확률을 덜 극단적으로 만든다.

과신 방지를 위해 상·하한을 **20%~80%**로 클리핑한다 (아침의 15~85%보다 보수적).

보정 규칙:
- 시장 폭 괴리(지수 상승 + adv_ratio < 0.4) → `p_up` 5%p 하향
- 미국 FOMC·CPI 등 대형 이벤트가 익일 새벽에 있으면 → `p_up`을 50% 쪽으로 30% 수축 (`p_up = 0.5 + (p_up - 0.5) * 0.7`)
- 옵션·선물 만기일 익일 → 동일하게 30% 수축

## 4. 등급 해석
| 총점 | 등급 | 익일 대응 |
|---|---|---|
| 75+ | 강세 | 공격적 대응 가능, 후보 3개, 종가 베팅 검토 |
| 65~74 | 우호 | 정상 진입, 후보 2개, 종가 베팅 금지 |
| 55~64 | 중립 | 소액·선별 진입, 후보 2개 |
| 45~54 | 약세 | 관망, 후보 1개, 비중 50% |
| 45 미만 | 위험 | 신규 진입 금지 |

## 5. 아침 점수와의 결합

익일 아침에 `market-open-sentiment`가 점수를 내면 두 점수를 결합해 최종 판단한다.

```
combined = 0.35 * 마감점수 + 0.65 * 익일아침점수
```

아침 가중치가 높은 이유: 시간적으로 가까운 정보가 더 강하다. 마감 점수는 **배경**이고 아침 점수는 **트리거**다.

단, 아래는 마감 점수가 아침 점수를 **거부**할 수 있는 케이스다.
```
마감점수 < 45 이면 익일 아침 점수와 무관하게 신규 진입 차단
마감 후 유상증자·CB 공시 종목은 아침 점수와 무관하게 후보 제외
```

## 6. 채점과 캘리브레이션

매일 아래를 DB에 남긴다.

| 컬럼 | 설명 |
|---|---|
| `date` | 거래일 |
| `morning_score` | 아침 점수 (없으면 NULL) |
| `morning_p_up` | 아침 상승 확률 |
| `close_score` | 마감 점수 |
| `close_p_up` | 익일 상승 확률 |
| `actual_dir` | 당일 지수 종가 방향 (1/0) |
| `actual_chg_pct` | 당일 등락률 |
| `next_open_gap_pct` | 익일 시가 갭 (마감 예측 채점용) |
| `adv_ratio` | 상승종목 비율 |
| `provisional` | 수급 잠정치 사용 여부 |

- **아침 점수 채점**: `morning_p_up` vs `actual_dir`
- **마감 점수 채점**: `close_p_up` vs 익일 `actual_dir` (또는 `next_open_gap_pct > 0`)
- 30거래일 이상 쌓이면 로지스틱 회귀로 가중치와 절편(55), 스케일(10)을 재적합한다.
- 브라이어 스코어 = `mean((p_up - actual_dir)^2)`. 0.25 미만이면 유의미, 0.20 미만이면 좋음.
- 항목별 기여도 분석: 각 서브스코어와 실제 방향의 상관을 월 1회 확인해, 상관이 0에 가까운 항목은 가중치를 줄인다.
- 신뢰구간이 확보되기 전에는 확률을 "참고 지표"로만 표기한다.

## 7. 데이터 결측 처리
- 항목 하나가 결측이면 해당 항목 가중치를 나머지에 비례 배분하고, 출력에 "부분 데이터" 배지를 표시한다.
- **투자주체 수급(0.25)이 결측이면 2개 결측과 동일하게 취급**한다. 가장 무거운 항목이므로 이것 없이 나온 점수는 신뢰도가 낮다.
- 2개 이상 결측이면 점수를 산출하지 않고 "데이터 부족"으로 표시하되, 계산 가능한 항목의 서브스코어는 표로 보여주고 "잠정 방향성"만 언급한다.

## 8. preclose 사전 점수 (14:30 / 15:15)

마감 점수는 15:30 이후에나 나온다. 그런데 **매수 판단은 15:19까지 끝내야 한다.**
그래서 같은 항목을 장중 데이터로 미리 계산한 `preclose` 점수를 별도로 둔다.
`scores` 테이블의 `phase` 컬럼에 `preclose_1430` / `preclose_1515` / `close`로 구분해 저장한다.

### 8-1. 가중치 (마감 점수와 다르다)

마감 동시호가와 마감 후 재료는 아직 존재하지 않으므로 항목에서 뺀다.

| 항목 | 비중 | 14:30 시점 계산법 |
|---|---|---|
| 종가 강도 (현재가 위치) | 0.25 | 마감 공식과 동일, 종가 대신 현재가 |
| 시장 폭 | 0.25 | 마감 공식과 동일 |
| 투자주체 수급 | 0.20 | 장중 잠정 순매수 (변동 큼, 방향만 신뢰) |
| 거래대금 (시간 정규화) | 0.20 | 아래 8-2 |
| 미국 지수선물 | 0.10 | ES=F / NQ=F 등락률 |

```
preclose_total = 0.25*S_종가강도 + 0.25*S_시장폭 + 0.20*S_수급
               + 0.20*S_거래대금 + 0.10*S_미국선물
```

### 8-2. 거래대금 시간 정규화 — 가장 많이 틀리는 부분

**14:30 누적 거래대금을 20일 "일간 총" 평균과 비교하면 안 된다.**
한국 시장 거래량은 U자형이라 14:30이면 하루치의 60~70%밖에 안 쌓인다.
그대로 나누면 항상 0.6~0.7배로 나와서 모든 날이 약세로 찍힌다.

반드시 **같은 시각 누적끼리** 비교한다.

```
amt_mult = (당일 14:30 누적 거래대금) / (20일간 14:30 시점 누적 거래대금의 평균)
```

우변 분모는 시장 데이터 제공처에 없다. **자체 DB에 매일 14:30·15:15 스냅샷을 쌓아
직접 만들어야 한다.** 최소 20거래일 축적 전에는 이 항목을 결측 처리하고 가중치를 재배분한다.

```
S_거래대금 = clip(50 + (amt_mult - 1.0) * 60, 0, 100)
```

### 8-3. 확률 변환 — 마감보다 좁게 clip

장중 데이터는 확정치가 아니므로 확신을 낮게 잡는다.

```
p_up = 1 / (1 + exp(-(preclose_total - 55) / 13))
p_up = clip(p_up, 0.30, 0.70)
```

마감 점수의 clip(0.20, 0.80)보다 좁다. 분모 13(마감은 10)도 더 완만한 기울기다.
**preclose 확률로 70%를 넘겨 표시하지 않는다.** 아직 모르는 게 많은 시점이다.

### 8-4. 두 시점의 역할 분담

| 시점 | 쓰임 | 액션 |
|---|---|---|
| 14:30 | 관찰 리스트 크기 결정 | <45면 그날 종가 베팅 자체를 취소 |
| 15:15 | 최종 진입 판정 | 70 미만이면 전량 포기 |

**14:30 점수보다 15:15 점수가 5점 이상 떨어졌으면 진입하지 않는다.**
막판에 밀리는 시장은 마감 동시호가에서 더 밀린다.

### 8-5. 사후 검증

`preclose_1515` 점수와 실제 `close` 점수의 차이를 매일 기록한다.

```
drift = close_total - preclose_1515_total
```

`drift`의 20일 이동평균이 −5 이하로 계속 나오면 preclose 가중치가 낙관 편향이다.
거래대금 항목 계수(60)를 낮추거나 수급 비중을 줄여 재보정한다.
