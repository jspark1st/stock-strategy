# 종가 베팅 실전 플레이북 (14:30~익일 오전)

전업 트레이더가 실제로 쓰는 마감 매수 루틴을 규칙으로 고정한 문서.
"마감 점수"가 시장 게이트라면, 이 문서는 **개별 종목 집행 규칙**이다.

---

## 0. 시간 구조를 먼저 정확히 알아야 한다

가장 흔한 착각: "3시 30분까지 보고 사면 된다."

| 구간 | 시각 | 실시간 체결 | 할 수 있는 일 |
|---|---|---|---|
| 접속매매 | 09:00~15:20 | O | 가격 보고 매수 |
| **마감 동시호가** | **15:20~15:30** | **X** | 주문 접수만. 예상체결가만 표시 |
| 종가 확정 | 15:30 | 단일가 일괄 체결 | — |
| 미체결 자동취소 | 15:35 | — | — |
| KRX 장후 시간외 종가 | 15:40~16:00 | O | 당일 종가 고정, 선착순 |
| NXT 애프터마켓 | 15:40~20:00 | O | 지정가만, 공매도 금지 |
| KRX 시간외 단일가 | 16:00~18:00 | 10분 단일가 | **2026-09-14 폐지** |
| KRX 애프터마켓 | 16:00~20:00 | O | **2026-09-14 신설** |

**결론: 실시간 가격을 보며 판단할 수 있는 마지막 시각은 15:20이다.**
따라서 판단 창은 `14:30~15:19`, 집행 창은 `15:20~15:28`이다.
"14:30~15:30에 결정"이라는 표현은 쓰지 말 것. 뒤 10분은 깜깜이 구간이다.

만기일(옵션·선물)에는 임의종료(random end)로 체결이 15:30 정각이 아니라
최대 30초 지연될 수 있다. **만기일은 종가 베팅 대상에서 제외한다.**

---

## 1. 3단계 판정 구조

한 번에 결정하지 않는다. 단계마다 후보를 줄인다.

```
14:30  preclose-screen  → 관찰 리스트 5~8개. 진입 금지. 알림만.
15:15  preclose-final   → 마지막 실시간 가격으로 매수/포기 확정. 2~3개.
15:20  execute          → 동시호가 주문 집행
15:26  confirm          → 예상체결가 재확인, 이탈 시 주문 취소
16:00~ overnight-guard  → DART 공시 감시, 악재 시 애프터마켓 청산
```

각 단계에서 **탈락은 자유롭게, 추가는 금지**한다. 15:15에 새 종목을 넣지 않는다.
장 막판에 눈에 들어온 종목은 준비된 종목이 아니다.

---

## 2. 종목 자격 필터 (14:30 스크리닝)

전부 AND 조건. 하나라도 안 맞으면 관찰 리스트에도 올리지 않는다.

### 2-1. 거래대금 — 1차 관문

```
당일 거래대금 >= 300억
  OR 최근 5거래일 내 거래대금 300억 이상인 장대양봉 캔들이 1개 이상 존재
```

당일이 아니어도 된다. 최근 3~5일 안에 대금이 터진 자리면 세력 물량이 이미 실려 있다는 뜻이다.
**거래대금 없는 종가 베팅은 익일 아침에 팔 상대가 없다.** 가장 흔한 실패 원인이 이것이다.

### 2-2. 나머지 필터

| 항목 | 기준 |
|---|---|
| 등락률 | +2% ~ +15% (급등 과열 제외) |
| 종가 위치 | `(현재가-저가)/(고가-저가) >= 0.7` |
| 이동평균 | 현재가 > 5일선, 5일선 > 20일선 선호 |
| 시가총액 | 1,000억 이상 |
| 거래대금 배수 | 20일 평균 대비 2배 이상 |
| 제외 | 관리종목·투자경고·정리매매·스팩·우선주·만기일 |
| 제외 | 당일 상한가 (익일 시가 갭에 물량 쏟아짐 → '관찰' 태그로만) |

### 2-3. 14:30~15:10 관찰 항목

필터를 통과해도 이 구간에서 무너지면 탈락시킨다.

- 고가 대비 −3% 이상 밀림 → 탈락
- 5일선 이탈 → 탈락
- 거래대금 증가가 멈추고 호가가 얇아짐 → 탈락
- 동일 섹터 대장주가 무너짐 → 동반 탈락

---

## 3. 15:15 최종 판정 (실시간 마지막 5분)

여기가 진짜 결정 지점이다. 아래 4개를 전부 확인한다.

1. **종가 위치 0.7 이상 유지 중인가** — 윗꼬리 길어지면 포기
2. **매수 호가 잔량이 매도 잔량보다 두꺼운가**
3. **시장 게이트를 통과했는가** — 마감 점수 예상치 55 이상
4. **미국 지수선물이 마이너스가 아닌가** — −0.5% 이하면 전량 포기

4번은 단일 거부권이다. 종목이 아무리 좋아도 미국 선물이 무너지면 사지 않는다.

---

## 4. 집행 — 동시호가 주문 기술

### 4-1. 체결 우선순위 트릭

동시호가는 **시간우선 원칙이 배제**되고 `가격우선 → 수량우선`만 적용된다.

따라서 **반드시 체결시키고 싶으면 상한가에 주문을 넣는다.**
상한가에 사지는 게 아니라, 15:30에 결정된 **종가로 체결**된다.
가격을 높게 불러 우선순위만 최상단으로 올리는 것이다.

지정가로 얌전히 넣으면 인기 종목은 물량을 못 받는다.
반대로 "안 사도 그만"인 종목은 지정가로 넣어 상단을 막는다.

```
반드시 담을 종목  → 상한가 주문 (체결가는 종가)
조건부 종목       → 지정가 주문 (상단 컷 = 15:19 종가 +0.5%)
```

### 4-2. 분할 진입

```
15:19 실시간 접속매매  50%   ← 가격 확정 가능
15:26 동시호가 주문    50%   ← 종가로 평균단가 조정
```

한 번에 다 넣지 않는다. 실시간분으로 최소 물량을 확보해두면
동시호가에서 물량을 못 받아도 포지션은 남는다.

### 4-3. 15:29 이후 금지

마지막 1~2분에 **허수 매수 호가로 예상체결가를 끌어올렸다가 취소**하는 패턴이 있다.
그걸 보고 따라 들어가면 실제 종가는 훨씬 낮게 찍힌다.

```
예상체결가는 15:25까지의 추세만 신뢰한다.
15:26~15:30 급변은 노이즈로 간주하고 무시한다.
15:26 시점 예상체결가가 15:19 종가 대비 -1% 이하로 밀리면 주문 전량 취소.
```

## 5. 비중 규칙

```
종가 베팅 총 비중 = min(마감 게이트 비중, 계좌의 10%)
종목당 최대       = 계좌의 5%
동시 보유         = 최대 2종목
```

마감 점수 70 미만이면 종가 베팅 자체를 하지 않는다.
3일 연속 규칙 준수율 80% 미만이면 비중 0.5배.

---

## 6. 청산 — 판이 바뀐 부분

### 6-1. 예전 전제는 더 이상 맞지 않다

과거 종가 베팅의 최대 약점은 "사고 나면 익일 09:00까지 손절이 불가능"이었다.
지금은 다르다. **NXT 애프터마켓이 15:40~20:00 실시간으로 돌아간다.**
2026-09-14부터는 KRX 애프터마켓(16:00~20:00)도 열린다.

즉 **마감 후 악재가 뜨면 그날 밤에 털고 나올 수 있다.**

### 6-2. overnight-guard 규칙

```
16:00~18:00  DART OpenAPI 5분 폴링
  유상증자 / 전환사채 / 감자 / 대주주 매도 / 횡령·배임 감지
    → 즉시 알림 + 애프터마켓 청산 지시

18:00~20:00  미국 지수선물 감시
  ES=F 또는 NQ=F가 -1.0% 이하
    → 보유 비중 절반 애프터마켓 청산

익일 08:30~09:00  장전 동시호가 예상체결가
  -3% 이하 갭다운 예상 → 시가 전량 청산 준비
```

### 6-3. 애프터마켓 청산 주의

애프터마켓은 유동성이 얇다. 2026년 7월 NXT 프리마켓에서
SK하이닉스가 단 1주 체결로 하한가를 찍은 사고가 있었고,
그 여파로 9월 14일부터 정적 VI(±10% 이탈 시 2분 정지)가 도입된다.

```
애프터마켓 청산은 반드시 지정가 분할.
시장가 금지. 얇은 호가에 시장가를 던지면 본인이 사고를 낸다.
1회 주문 수량은 해당 호가 잔량의 30%를 넘기지 않는다.
```

### 6-4. 정상 청산

악재가 없으면 **익일 오전 중 매도**가 원칙이다.

| 시나리오 | 대응 |
|---|---|
| 시가 +3% 이상 갭업 | 시가에 절반 익절, 나머지 09:30까지 |
| 시가 +1~3% | 09:00~09:30 분할 익절 |
| 시가 −1~+1% | 09:30까지 관찰, 5분봉 음전 시 전량 |
| 시가 −1% 이하 | **시가 전량 손절.** 버티지 않는다 |

**타임스톱: 10:00까지 전량 청산.** 종가 베팅은 갭을 먹는 전략이지 스윙이 아니다.
오전에 못 팔면 그날 판단이 틀린 것이다.

## 7. 자동화 매핑

| 단계 | 시각 | 구현 |
|---|---|---|
| preclose-screen | 14:30 | 조건검색 API → 관찰 리스트 텔레그램 |
| 관찰 | 14:30~15:10 | 5분 폴링, 탈락 조건 감지 시 제외 알림 |
| preclose-final | 15:15 | 4개 체크 자동 판정 → 매수 지시 알림 |
| execute | 15:19 / 15:26 | 주문 API 2회 분할 |
| confirm | 15:26 | 예상체결가 −1% 체크 → 취소 API |
| close | 15:35 | 체결 결과 trades 테이블 기록 |
| overnight-guard | 16:00~20:00 | DART 폴링 + 미국선물 감시 |
| exit | 익일 09:00~10:00 | 시나리오별 청산 지시 |

**주문 API 자동 집행은 반드시 수동 승인 단계를 둔다.**
15:15 판정 결과를 텔레그램으로 보내고, 사용자가 승인 버튼을 눌러야 주문이 나가게 한다.
동시호가 자동 주문은 오류 시 회수가 불가능하다.

## 8. HTS 조건검색식 (14:30 스크리닝용)

```
[대상] 코스피 + 코스닥 전체
[제외] 관리종목, 투자경고, 정리매매, 스팩, 우선주, ETF, ETN

1. 주가등락률: 당일 2% 이상 15% 이하
2. 거래대금: 당일 300억 이상
   OR 5일 내 일거래대금 300억 이상 1회 이상
3. 거래대금 비율: 당일 / 20일평균 >= 200%
4. 주가위치: (현재가-저가)/(고가-저가) >= 0.7
5. 이동평균: 현재가 > 5일선
6. 시가총액: 1000억 이상
7. 현재가: 1,000원 이상
```

검색 시각을 14:30으로 고정한다. 장중 계속 돌리면 노이즈만 늘어난다.

## 9. 이 전략이 통하지 않는 날

아래에 해당하면 **종가 베팅 전면 중단**이다.

- 옵션·선물 만기일 및 그 전날
- MSCI·FTSE 리밸런싱일
- 익일 FOMC, CPI, 고용지표 발표
- 미국 증시 휴장 다음날 (선물 신호 없음)
- 마감 점수 70 미만
- 최근 5거래일 종가 베팅 승률 40% 미만 (일시 중단 후 재점검)
