# 복기와 익일 준비 플레이북

전업 단타 트레이더의 검증된 마감 루틴을 코드화 가능한 규칙으로 정리한다.
핵심 명제: **돈은 아침에 벌지만 실력은 저녁에 는다.**

## 1. 아침 점수 채점

마감 직후 가장 먼저 하는 일. 5분이면 끝난다.

| 항목 | 확인 방법 | 판정 |
|---|---|---|
| 방향 적중 | `morning_p_up > 0.5` 이고 지수 상승 → 적중 | O/X |
| 강도 적중 | 예측 등급(강세/우호/중립/약세)과 실제 등락률 구간 일치 | O/X |
| 게이트 적정성 | 게이트가 허용한 후보 수 vs 실제로 수익 난 후보 수 | 과대/적정/과소 |
| 항목별 오차 | 어떤 서브스코어가 실제와 가장 어긋났는지 1개 지목 | 항목명 |

**항목별 오차를 매일 하나씩 기록하는 게 캘리브레이션의 원료다.** 30일 모이면 어떤 항목이 구조적으로 틀리는지 보인다.

브라이어 스코어 갱신:
```
brier = mean((p_up - actual_dir)^2)   # 최근 30거래일 롤링
```
- 0.20 미만: 모델 신뢰 가능, 확률 그대로 사용
- 0.20~0.25: 참고 지표로만 표기
- 0.25 이상: 확률 표기 중단, 등급(강세/중립/약세)만 표기

## 2. 매매일지 스키마

사용자가 매매를 했다면 아래를 반드시 채운다. 빈칸이 있으면 복기가 아니라 감상문이다.

| 컬럼 | 예시 | 비고 |
|---|---|---|
| `ticker` | 005930 | |
| `entry_type` | 갭눌림 / 전고돌파 / 눌림목반등 / 종가베팅 | 사전 정의된 4개만 허용 |
| `entry_time` | 09:14:22 | |
| `entry_price` | 71,200 | |
| `exit_time` | 09:31:05 | |
| `exit_price` | 72,400 | |
| `size_pct` | 20 | 계좌 대비 비중 |
| `pnl_pct` | +1.69 | |
| `planned_stop` | 70,400 | 진입 **전에** 정한 값 |
| `stop_respected` | true | 손절가 이탈 후에도 들고 있었으면 false |
| `timestop_respected` | true | 15분 룰 준수 여부 |
| `plan_deviation` | 없음 / 추격매수 / 물타기 / 조기청산 | |
| `market_score` | 81 | 당일 아침 점수 |

### 규칙 준수율 (매일 계산)
```
discipline = (stop_respected + timestop_respected + (plan_deviation == '없음')) / 3
```

**핵심 원칙: 손익보다 준수율을 먼저 본다.**
- 준수율 100% + 손실 → 정상. 시장이 안 맞은 날이다. 규칙을 바꾸지 않는다.
- 준수율 66% 이하 + 수익 → **가장 위험한 날**. 규칙 위반이 보상받았으므로 다음에 반복한다. 반드시 경고를 띄운다.
- 준수율이 3일 연속 80% 미만이면 익일 비중을 자동 50% 축소한다.

## 3. 익일 후보 필터

마감 데이터로 익일 관심종목을 뽑는다. 아래 **모두** 충족해야 후보다.

| 필터 | 기준값 | 이유 |
|---|---|---|
| 당일 등락률 | +3% ~ +15% | 15% 초과는 이미 소진, 3% 미만은 재료 약함 |
| 거래대금 | 500억원 이상 | 유동성. 이하는 슬리피지가 수익을 먹는다 |
| 거래대금 배수 | 20일 평균의 2배 이상 | 신규 자금 유입 증거 |
| 종가 위치 | `close_pos >= 0.7` | 고가권 마감. 윗꼬리 긴 종목 제외 |
| 시가총액 | 1,000억원 이상 | 작전 리스크 회피 |
| 5일선 | 종가가 5일선 위 | 추세 정렬 |
| 마감 후 공시 | 유상증자·CB·감자·대주주매도 **없음** | 하나라도 있으면 즉시 탈락 |
| 상한가 여부 | 상한가 마감은 별도 취급 | 익일 갭 예측 불가, 후보 아닌 관찰 대상 |

### 우선순위 정렬
```
rank_score = 0.4 * 거래대금배수_정규화
           + 0.3 * close_pos
           + 0.2 * 섹터_주도_플래그      # 오늘 주도 섹터 소속이면 1
           + 0.1 * 외국인_순매수_플래그
```
상위 5개만 관찰 리스트에 올리고, 실제 후보는 익일 아침 게이트가 허용하는 개수만 남긴다.

## 4. 익일 타점 3종

| 유형 | 진입 조건 | 손절 | 목표 | 무효화 |
|---|---|---|---|---|
| **갭 눌림** | 갭상승 +1~4% 출발 후 09:05~09:20에 시가 부근까지 눌렸다가 5분 체결강도가 20분선 상향 돌파 | 시가 −1.5% | 전일 고가 또는 +3% | 시가 이탈 후 3분 내 미회복 |
| **전고 돌파** | 전일 고가를 거래량 동반 돌파, 돌파 시 5분 거래량이 직전 5분의 2배 이상 | 전일 고가 −1% | 돌파폭의 1.5배 | 돌파 후 5분 내 전일 고가 아래로 회귀 |
| **눌림목 반등** | 갭 없이 출발, 5일선 지지 확인 후 반등, 체결강도 110 이상 | 5일선 −1% | 전일 고가 | 5일선 종가 이탈 |

**모든 유형 공통**
- 타임스톱: 진입 후 15분 내 +1% 미달이면 무조건 청산.
- 09:00~09:05는 진입 금지 구간. 변동성이 규칙을 무력화한다.
- 하루 손절 2회 발생 시 당일 매매 종료. 예외 없음.
- 한 종목 최대 비중 계좌의 25%.

### 4-1. 손절가·목표가 산정 — ATR 기반 (일봉)

위 표의 손절/목표는 진입 타점의 구조적 기준값이다. 하지만 **정확한 가격 수준과 손익비는 일봉 ATR(14)로 계산**해서 구조적 기준값과 대조한다. 둘 중 더 타이트한(보수적인) 쪽을 실제 손절가로 쓴다.

```
ATR(14) 배수: 단기 1.0~1.2×(손절)/2.0~2.4×(목표), 스윙 1.5×/3.0~4.5×
b = 목표배수 / 손절배수
p_breakeven = 1 / (1 + b)
edge = p_used(익일 p_up 또는 종목 승률 추정) - p_breakeven
```

`edge <= 0`이면 타점 조건을 만족해도 후보에서 제외한다. `edge > 0`이면 켈리 공식(1/2 축소)으로 비중을 구해 기존 25% 상한과 비교해 더 작은 값을 쓴다. 전체 공식·배수표·계산 예시는 `references/atr-risk-sizing.md` 참조.

## 5. 종가 베팅 (오버나이트) 규칙

가장 위험한 전략이므로 게이트를 3중으로 건다. **셋 다 충족될 때만 허용한다.**

```
조건 1: 마감 총점 >= 70
조건 2: 해당 종목 15:20~15:30 동시호가 매수잔량 우위 (bid_ratio >= 0.55)
조건 3: 미국 지수선물이 플러스 (또는 최소 -0.2% 이상)
```

추가 제약
- 계좌의 **10%를 초과하지 않는다.** 갭하락에는 손절이 작동하지 않는다.
- 마감 후 18:00까지 공시를 재확인하고, 유상증자·CB·대주주매도가 뜨면 익일 시초가 무조건 청산.
- 익일 갭상승 +2% 이상이면 시초가에 절반 익절, 나머지는 위 타점 규칙으로 관리.
- 익일 갭하락이면 시초가 −3% 이하일 때 즉시 전량 청산. 반등 기다리지 않는다.
- FOMC·CPI·고용지표 발표 전날은 종가 베팅 전면 금지.

## 6. HTS 조건검색식 (익일 후보 스크리닝)

한국투자증권·키움 조건검색에 그대로 옮길 수 있는 형태.

```
1. 주가등락률: 당일 종가 기준 등락률 3% 이상 15% 이하
2. 거래대금: 당일 거래대금 500억원 이상
3. 거래량비율: 당일 거래량 / 20일 평균거래량 200% 이상
4. 주가위치: (종가 - 저가) / (고가 - 저가) 70% 이상
5. 시가총액: 1000억원 이상
6. 이동평균: 종가 > 5일 이동평균
7. 제외: 관리종목, 투자경고, 정리매매, 스팩, 우선주
```

조건 1~7을 AND로 결합. 결과가 20개를 넘으면 조건 3을 250%로, 조건 2를 800억원으로 올린다.

## 7. 자동화 매핑

| 플레이북 규칙 | 자동화 구현 |
|---|---|
| 아침 점수 채점 | 16:30 크론 → `scores` 테이블 조인 → 브라이어 갱신 |
| 매매일지 입력 | 증권사 API 체결내역 조회 → 자동 채움, `plan_deviation`만 수기 |
| 규칙 준수율 경고 | 준수율 < 0.8이 3일 연속이면 텔레그램 경고 + 익일 게이트 비중 0.5배 |
| 익일 후보 필터 | 15:45 배치 → 조건검색 API 또는 전종목 스냅샷 필터링 |
| 마감 후 공시 감시 | 16:00~18:00 DART OpenAPI 5분 폴링 → 후보 종목 공시 뜨면 즉시 탈락 처리 |
| 종가 베팅 판정 | 15:25 트리거 → 3조건 동시 평가 → 충족 시에만 알림 |
| 익일 확률 재보정 | 익일 07:30 크론 → 야간선물·미국 마감 반영 → `close_p_up` 갱신 |

**DART OpenAPI 폴링은 필수다.** 마감 후 악재 공시를 놓치면 위 필터가 전부 무의미해진다.
