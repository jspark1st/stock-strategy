# 장 마감 기준 시장 점수화 + 데일리 복기

한국(및 선택적으로 미국) 주식 시장의 **장 마감 국면**을 데이터로 점수화하고,
**마감 강도 / 익일 상승 확률 / 익일 하락 확률 / 오늘의 복기**를 한 페이지에 요약한다.

이 스킬은 `market-open-sentiment`(장전·장 초반)의 **짝**이다. 아침 점수가 예측이라면 마감 점수는 **채점과 다음 예측**이다.
의사결정의 시작점은 항상 이 스킬이다 — 이 스킬이 확정하는 지수 방향성 판단을 `market-open-sentiment`가 다음날 아침
실제 시장 데이터로 재평가(승인/축소/취소)해 최종 실행 여부를 결정한다. 현재 둘 사이 자동 연결 저장소가 없으므로,
아래 출력 형식 10번 "재평가 핸드오프 블록"을 마감 브리핑에 반드시 함께 내고, 사용자가 다음날 아침
`market-open-sentiment` 세션에 그대로 붙여넣도록 안내한다.

## 언제 사용하는가

- "오늘 장 마감 시황 점수로 알려줘", "마감 브리핑 해줘"
- "오늘 매매 복기해줘", "아침 점수 맞았는지 채점해줘"
- "내일 상승 확률 / 하락 확률 대시보드 만들어줘"
- "투자자별 수급 정리해줘", "외국인·기관 순매수 어땠어?"
- "내일 관심종목 뽑아줘", "종가 베팅 후보 있어?"
- "마감 데이터 수집·저장 파이프라인 설계해줘", "데일리 리뷰 자동화해줘"

## 기본 원칙

1. **역할 분리를 반드시 지킨다.**
   - Perplexity/뉴스 API = 마감 후 재료 해석·요약·태깅 (시세 소스로 쓰지 않는다)
   - 증권사 Open API = 원천 데이터 (종가, 투자자별 매매동향, 거래대금, 상승/하락 종목 수)
   - 자체 스코어링 엔진 = 판단
   - 대시보드/봇 = 전달
2. **모든 출력은 한국어**, 개념 설명보다 실행 가능한 설계·워크플로우 우선.
3. **점수는 항상 근거 항목별로 분해**해서 표로 보여준다. 총점만 던지지 않는다.
4. **복기는 반드시 숫자로 한다.** "느낌이 좋았다"는 기록이 아니다. 진입가·청산가·보유시간·규칙 준수 여부를 남긴다.
5. **투자 조언이 아님을 명시**하고, 리스크를 함께 적는다.
6. 수치·뉴스는 반드시 최신 데이터로 확인한다. 기억에 의존해 시세를 쓰지 않는다.
7. **아침 점수와 마감 결과를 항상 연결한다.** 채점 없는 예측은 반복해도 실력이 늘지 않는다.

## 표준 워크플로우

### A. 마감 브리핑/점수 산출 요청일 때

1. **데이터 수집**
   - `finance` 커넥터 또는 `finance/finance-markets` 스킬로 KOSPI/KOSDAQ 종가, 원달러, 미국 3대 지수 전일 종가, 미국 지수선물, VIX, 업종별 등락 확인.
   - 웹 검색으로 마감 뉴스: 장중 주도 섹터, 특징주, 마감 후 공시·실적, 익일 예정 이벤트(경제지표, FOMC, 옵션만기, 지수 리밸런싱).
   - 가능하면 증권사 API 수집분(투자자별 순매수, 거래대금, 상승/하락 종목 수, 상한가 수, 프로그램 매매)을 사용자로부터 받거나 파이프라인 값을 읽는다.
2. **점수 계산**: `references/scoring-close.md`의 가중치와 공식을 그대로 적용한다.
3. **출력 포맷**: 아래 "출력 형식" 섹션의 표 구조를 따른다.
4. **아침 점수가 있으면 반드시 채점한다.** `references/review-playbook.md`의 1장.
5. **익일 후보를 함께 요구하면** `references/review-playbook.md`의 3장 필터와 4장 타점 규칙을 적용한다.

### B. 시스템 구축 요청일 때

1. 대상 시장(국내 전용 / 미국 포함)과 실행 환경을 먼저 확정한다.
2. `references/architecture-close.md`로 수집→저장→채점→점수→표시 아키텍처 제시.
3. 증권사 API 연동 절차·엔드포인트는 `market-open-sentiment` 스킬의 `references/broker-api.md`를 그대로 재사용한다. 마감 전용으로 추가로 필요한 것은 `references/architecture-close.md` 2장에 정리되어 있다.
4. `references/codex-prompts-close.md`의 역할 분배 프롬프트를 그대로 제공.
5. API 키 저장은 `market-open-sentiment`의 `references/secrets-setup.md`와 동일한 방식을 쓴다. 같은 서버에 올린다면 `.env`를 공유한다.
6. 프로토타입이 필요하면 `assets/dashboard-template.html`을 복사해 수정 후 배포한다.

## 점수 체계 (요약)

| 항목 | 지표 | 비중 |
|---|---|---|
| 종가 강도 | 일중 고저 대비 종가 위치, 등락률 | 20% |
| 시장 폭 | 상승/하락 종목 비율, 상한가·하한가 수 | 20% |
| 투자주체 수급 | 외국인·기관 순매수 금액, 프로그램 매매 | 25% |
| 거래대금 | 당일 거래대금 / 20일 평균 | 15% |
| 마감 동시호가 | 15:20~15:30 지수·주도주 변화 방향 | 10% |
| 마감 후 재료 | 시간외 공시, 야간선물, 미국 선물 방향 | 10% |

해석 기준: **75점 이상 = 익일 공격적 대응 / 55~74점 = 선별 대응 / 54점 이하 = 익일 관망**.
상세 공식과 확률 변환식은 `references/scoring-close.md` 참조.

## 실전 게이트 (반드시 적용)

마감 점수는 **익일 진입 후보 개수와 비중을 제한하는 게이트**로 쓴다.
아침 점수 게이트와 곱해서 최종 비중을 정한다 — 마감이 강했어도 익일 아침이 무너지면 진입하지 않는다.

```
마감 총점 < 45   → 익일 신규 진입 차단, 관망 알림만
45 ~ 54          → 익일 후보 최대 1개, 비중 50% 축소
55 ~ 74          → 익일 후보 최대 2개, 정상 비중
75 이상          → 익일 후보 최대 3개, 공격적 대응 허용

최종 비중 = min(마감 게이트 비중, 익일 아침 게이트 비중)
```

**종가 베팅(오버나이트)은 별도 게이트를 쓴다.**

```
마감 점수 70 이상
  AND 종목 거래대금 300억 이상 (또는 최근 5일 내 300억 장대양봉 존재)
  AND 종가 위치 >= 0.7
  AND 미국 지수선물 > −0.5%   ← 단일 거부권
  AND 만기일·리밸런싱일 아님

총 비중 = min(마감 게이트, 계좌의 10%) · 종목당 5% · 동시 최대 2종목
```

집행 기술(동시호가 상한가 우선순위 주문, 분할 진입, 15:29 이후 금지)과 청산 규칙은
`references/closing-bet-playbook.md`에 있다. **종가 베팅 질문이면 반드시 이 파일을 읽는다.**

익일 후보를 낼 때는 항상 **진입 타점 유형(갭 눌림 / 전고 돌파 / 눌림목 반등), 손절가, 목표가, 무효화 조건**을 함께 명시한다. 이 4개가 없으면 후보로 내지 않는다.

**손절가·목표가는 감으로 정하지 않고 ATR 기반으로 계산한다.** 일봉 ATR(14)에 배수(k1/k2)를 곱해 손절·목표 거리를 정하고, 그 손익비(b=k2/k1)를 `close_p_up`(또는 종목별 승률 추정)과 결합해 손익분기 승률·기대값(edge)·켈리 비중까지 한 줄로 낸다. 공식과 예시는 `references/atr-risk-sizing.md` 참조. **`edge <= 0`인 종목은 시장 게이트를 통과해도 후보에서 제외한다.**

## 출력 형식

마감 브리핑은 항상 아래 순서로 낸다.

1. **한 줄 결론** — 오늘 시장 성격과 익일 대응 강도.
2. **마감 점수 / 익일 상승 확률 / 익일 하락 확률** — 숫자 3개.
3. **항목별 점수표** — 항목, 관측값, 점수, 코멘트.
4. **아침 점수 채점** — 아침 예측 점수, 실제 결과, 적중 여부, 누적 브라이어 스코어. (아침 데이터가 없으면 "채점 불가"로 표기하고 생략)
5. **오늘의 시장 성격** — 주도 섹터, 소외 섹터, 순환매 여부, 특징주 3~5개(출처 링크 포함).
6. **오늘의 매매 복기** — 사용자가 매매 기록을 제공했을 때만. 규칙 준수율과 개선점 1~2개.
7. **익일 시나리오** — 상승 시나리오 / 하락 시나리오 / 트리거 이벤트.
8. **익일 관심종목** — 게이트가 허용하는 개수만. 타점·손절·목표·무효화 4종 세트 필수.
9. **주의 신호** — 만기일, 지수 리밸런싱, 예정 지표, 과열·선반영 경고.
10. **재평가 핸드오프 블록** — `market-open-sentiment`의 `references/reassessment.md` 0장 템플릿 형식으로 마감 총점·p_up/p_down·등급·게이트 결과(후보 개수·비중)·잠정치 여부·무효화 이슈·종가 베팅 진입 종목을 복사붙여넣기 하기 쉬운 코드블록으로 따로 정리한다. 이 블록이 없으면 사용자가 다음날 아침 재평가를 진행할 수 없다.

시각화가 도움이 되면 `visualize` 스킬을 로드해 점수 게이지·수급 막대·업종 히트맵을 추가한다.

## 리스크·법적 주의

- 증권사 API 약관상 **데이터 재배포 제한**을 확인한다. 외부 공개 대시보드에 원천 시세를 그대로 노출하지 않는다.
- **투자자별 매매동향 확정치는 장 마감 직후 값이 아니다.** 잠정치와 확정치가 다르며 KRX 확정치는 보통 18시 이후에 나온다. 잠정치로 점수를 냈다면 반드시 "잠정" 배지를 붙이고, 확정치 반영 후 점수를 갱신한다.
- **종가 베팅은 갭하락 리스크를 떠안는다.** 다만 예전처럼 "익일 09:00까지 손절 불가"는 아니다. NXT 애프터마켓(15:40~20:00)이 실시간으로 돌고, 2026-09-14부터 KRX 애프터마켓(16:00~20:00)도 열린다. 마감 후 악재가 뜨면 당일 밤에 청산할 수 있으므로 overnight-guard를 반드시 구현한다.
- **애프터마켓은 유동성이 얇다.** 2026년 7월 NXT 프리마켓에서 SK하이닉스가 단 1주 체결로 하한가를 찍은 사고가 있었고, 9/14부터 정적 VI(±10% 이탈 시 2분 정지)가 도입된다. **애프터마켓 청산은 지정가 분할만, 시장가 금지.**
- **마감 동시호가 마지막 1~2분은 허수 호가 구간이다.** 예상체결가를 띄웠다가 15:29에 취소하는 패턴이 있다. 예상체결가는 15:25까지의 추세만 신뢰한다.
- **동시호가 자동 주문은 수동 승인 단계를 둔다.** 15:15 판정 결과를 알림으로 보내고 사용자 승인 후 주문이 나가게 한다. 동시호가 오류 주문은 회수가 불가능하다.
- 마감 후 공시는 16:00~18:00에 집중된다. 16:30에 낸 점수는 이후 공시로 뒤집힐 수 있으므로 18:00 재확인 루틴을 넣는다.
- 브라이어 스코어가 0.25 이상이면 확률 모델을 신뢰하지 말고 "참고 지표"로만 표기한다.
- API 키·계좌 토큰은 서버 환경변수/시크릿 매니저로만 관리하고 프론트에 절대 노출하지 않는다.
- 산출물에 "투자 판단의 참고 자료이며 투자 권유가 아님"을 표기한다.
