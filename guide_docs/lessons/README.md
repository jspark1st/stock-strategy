평가 원문은 [`../source/`](../source/) · 의도된 공식 분기는 [`../DIVERGENCES.md`](../DIVERGENCES.md).

## 한 줄로 읽는 교훈

이 전략의 돈은 **오버나이트 리스크 프리미엄(구조)** 에서 나오지, 마감 총점의 영리함에서 나오지 않는다.
모델의 역할은 수익 창출보다 **하락 레짐에서 진입을 거르는 게이트**에 가깝다.
유일한 검증된 판별 엣지는 **개장전 간밤 미국장 틸트**(특히 KOSPI). 마감 시점에 그걸 쓰면 미래참조다.

| 6 (`evaluation6.md`) | 63점. 인프라는 있고 예측기는 없다 | 게이트·지평·백업·Gemini·p_up 격하 |

평가 점수를 올리려고 피처를 추가하는 것은 교훈이 아니다. AUC·Brier·paper 순손익이 척도다.

## 라벨 · 확률 읽는 법

- **주:** `overnight_correct` / `primary_*` — 종가 → 익일 시가
- **보조:** close→close / `secondary_*` — 버리지 않음(비교)
- p_up 헤드라인: 정상 캘리브면 「익일 시가 상승 확률」. `slope_at_floor` 면 「상승 기저율(예측 아님)」
- n<40: 화면 숫자 숨김. 적중 100%를 모델 실력으로 읽지 않음

## SoT 와의 관계

`sample/` 은 설계 정본. 하네스로 정당화된 확장만 `DIVERGENCES.md` 에 산다.
표에 없는 산식 차이 → 버그 → SoT 로 되돌린다 (예: foreign_streak 1일 보너스).
철회된 분기는 표에서 지우지 않고 **철회**로 남긴다 (vol_tilt #2).
