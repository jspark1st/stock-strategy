### 결정적 발견 5가지

**① 진입 게이트가 구조적으로 절대 열리지 않았다.**
`confidence = 완전성 × 신호일치도`([scoring.py](../../src/scoring.py))인데 일치도는
`min(bull_w, bear_w) ≥ 0.35` 면 0 으로 포화한다. 코어 5~6팩터(0.20/0.20/0.25/0.15/0.15) 분포에서
그건 **평상시**다 — 8/28 실측 KOSPI bull 0.500/bear 0.450, KOSDAQ 0.550/0.400 → 둘 다 일치도 0.00
→ 신뢰도 0.00 → `min_confidence 0.5` 미달 → 영구 차단. **`paper_trades` 0행**, 로드맵 L2 이상 정지.
BTC 게이트 335슬롯 통과 0회와 같은 병리가 주식에서 반복됐는데, 주식은 아무도 측정하지 않았다.

**② 라벨과 실거래 지평이 반대로 갔다.**
```
close→close (채점 라벨) : 12/16 = 75%
close→open  (실제 전략) :  3/10 = 30%     평균 −0.217%/회 · AUC 0.333
```
8/25 에 n=4 로 "노이즈일 수 있음"으로 등재했으나 표본이 늘며 방향이 유지됐다. 매일 채점하는 숫자가
실제로 돈을 버는 숫자가 아니었다.

**③ 캘리브레이션이 정직하게 작동한 결과, p_up 이 상수가 됐다.**
p_up 표준편차 0.125(원시 0.227), 실질 범위 0.50~0.66. 적합 기울기가 하한 클램프(0.005)에 고착 =
적합기가 "총점과 결과는 무관"을 학습해 총점 정보를 버리고 기저율만 출력. 헤드라인 "익일 상승확률"이
예측이 아니라 기저율 표시였다.

**④ Gemini(계산·검증 담당)가 프로덕션에서 무성 사망.**
라이브 재현: `maxOutputTokens=1400` 을 사고 토큰 1,349가 먹어 `finishReason=MAX_TOKENS`·본문 0자 →
`parts` KeyError → `except: continue` → 3모델 전멸 → None. 8/28 실제 로그 `Gemini 미실행`.
3-LLM 분업이 2-LLM 이었고, 빠진 게 수치 정합성 교차검증 담당이었다.

**⑤ 학습 DB 사본이 하나뿐.**
`db/history.db` gitignore·심볼릭 1개, `remote.py` 는 이 서버에서 local-only degrade.
재구성 불가능한 유일 자산이 무방비.

## 2. 수정 내역 (브랜치 `fix/gate-and-horizon`, 테스트 292 → **305**)

### ① 게이트 — 이중계상 제거 + 상시 측정
- `confidence = 데이터 완전성`(× 표본보정). 신호 불일치는 **이미 p_up 을 최대 20% 수축**시키고
  게이트가 그 p_up 에 확률 임계를 또 건다 → 신뢰도에 다시 곱하는 건 같은 사실의 3중 처벌이었다.
- **임계(`min_confidence` 0.5·`min_prob` 0.60)는 그대로.** 통과율을 올리는 완화가 아니라, 지표의
  중복 정의를 고친 것. 실증(과거 18회차 재판정):

  | | 구 게이트 | 신 게이트 |
  |---|---:|---:|
  | 통과 | **0 / 18** | **3 / 18** (전부 KOSPI 중립·우호 + p_up ≥ 0.60) |

  통과분 실현(종가→시가): −0.23% · +2.76% (n=2, 통계적 의미 없음 — 이제야 **표본이 쌓이기 시작**).
- `daily.entry_allow` · `entry_blocked` 컬럼 + `store.gate_stats()` + health_check 가
  **연속 10회 통과 0 이면 경보**. 재발을 사람이 아니라 시스템이 잡는다.

### ② 지평 — 주 라벨을 실거래로 전환
- `DIRECTION_LABEL = next_open_return_sign`. `accuracy()` 가 `primary_*`(open) / `secondary_*`(close)
  분리, `fit_calibrator(label="open")` 기본, 부트스트랩도 `overnight_label` 로 재적합.
- close→close 는 **폐기하지 않고 보조 기록**(캘리브 연속성·과거 비교).
- ⚠️ 재적합 결과가 ③을 더 나쁘게 확인해준다:

  | 시장 | 적합 기울기 | 원시 기울기 | 총점 전 구간이 만드는 확률 폭 |
  |---|---:|---:|---:|
  | KOSPI | 0.005 (하한) | +0.0034 | 8.8%p |
  | KOSDAQ | 0.005 (하한) | **−0.0106 (역방향)** | 7.5%p |

  → **총점은 어느 지평에서도 방향 정보를 갖지 않는다**(단일레짐 149표본). KOSDAQ 은 오히려 역방향이며
  하한 클램프가 그걸 가려주고 있었다.

### ③ 백업
`scripts/backup_db.py` + `auto_backup.sh`(cron `30 23 * * *`, auto_final 에도 1회).
sqlite **온라인 백업 API**(쓰기 중에도 일관 — `cp` 는 깨진 파일이 나올 수 있다) → `integrity_check`
→ gzip → 14벌 순환. 저장은 **repo 밖** `~/overnight_report_backups`. 검증 실패분은 남기지 않는다
(깨진 백업이 '있다'가 없느니만 못하다). 복원 검증 완료.

### ④ Gemini 복구 + 무성 실패 금지
`llm.gemini_call()` 공용 호출기 — 사고예산 0 우선(미지원이면 재시도) · 출력 8192 ·
**빈 응답을 성공으로 취급 안 함** · `_LAST_ERROR` 에 사유 기록. run_close 가 키가 있는데 실패면 경보.
라이브 파이프라인 확인: `Perplexity ✓ / Gemini 초안 ✓ / Claude 합성 ✓` (오전엔 `Gemini 미실행`).

### ⑤ 확률 격하
`calibration.fit` 이 `slope_at_floor`·`prob_span_pp`·`raw_slope` 를 산출 → 렌더가 헤드라인 라벨을
**"상승 기저율(예측 아님)"** 으로 낮추고 확률 폭·역방향 사실을 명시. 정상 캘리브면
**"익일 시가 상승 확률"**(지평을 라벨에 각인 — 익일 '종가'가 아니다).
라이브 렌더 확인: `56% 상승 기저율(예측 아님)` + `캘리브 기울기 하한 고착 … 확률 폭 8.8%p`.
