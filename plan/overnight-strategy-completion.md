## 1. CLOSE_ENTRY — 종가 진입 판단 🟢 [S~M]
평가: **판정 시각 고정** + "신호 산출 시각"과 "동시호가 주문 제출 시각" 분리.
- [ ] 신호 산출 시각을 config 로 고정(예: `signal_at=15:00`), 주문 제출 시각 별도(`order_submit=15:20~15:28`)
- [ ] 진입 허용 게이트(전부 참일 때만):
  - [ ] 필수 데이터 충족률 = 100% (evaluation2 P0-1)
  - [ ] 데이터 신선도 ≤ 3분
  - [ ] 보정 후 확률 p ≥ 0.60 (임계 config)
  - [ ] 시장 레짐 허용 구간 (변동성 국면 — `atr.robust_atr` regime 활용)
  - [ ] 이벤트 잠금 없음 (`EVENT_LOCK`)
  - [ ] 예상 스프레드·괴리율 한도 이내 (ETF 실행엔진, P1-7)
  - [ ] 일일 손실·재진입 한도 미도달 (config)
- [ ] **진입 근거 = `총점`이 아니라 "기대값 검증된 조건 조합"** (🟡 조합의 edge는 표본 후 확정)
- 매핑: `config/strategy_config.json`, 게이트 로직(scoring/gate 확장).

## 2. AFTER_CLOSE_CONFIRM — 마감 후 확정 컨펌 🟢 [M]
평가: 확정값이 잠정 신호를 뒤집을 때 **행동 규칙을 코드로 고정**. (지금은 diff만 보여줌)
- [ ] `confirm_diff` 에 **행동 판정** 추가:
  - [ ] **유지(HOLD)**: 방향 동일 + 확률 하락폭 < 10%p + 데이터 충돌 없음
  - [ ] **축소(REDUCE)**: 확률 10~20%p 약화 or 수급·종가강도 기준선 하회 or 해외 이벤트 경고
  - [ ] **청산예약(EXIT_QUEUE)**: 잠정↔확정 방향 반전 or 확정 수급 반대로 임계 초과 or 체결가 허용범위 이탈
- [ ] 예: 15:00 `p_down=0.77` → 확정 후 `0.53` 이면 "아직 하락 우위"로 해석하지 말고 **전제 붕괴로 분류**
- [ ] 이 판정을 스냅샷에 불변 저장(P0-3)
- 매핑: `run_close`(16:30 회차) + `render.build_confirm_diff` 에 행동 배지, `store` 저장.

## 4. PREOPEN_RECONFIRM — 08:50 최종 상태 🟢 [M]
평가: 단순 재평가가 아니라 **보유 유지/청산 결정**. 시간표 + 4상태.
- [ ] 시간표: 08:30~45 수집 → 08:45~50 재산출 → 08:50 상태 확정 → ~08:59 주문계획/취소 → 09:00 실행
- [ ] **최종 상태 4개**(규칙 기반, 지금 가능):
  - [ ] `HOLD_FULL` 전제 유지·갭 정상 → 보유 유지
  - [ ] `REDUCE` 전제 약화(확률·품질 하락) → 개장 후 일부 축소
  - [ ] `EXIT_OPEN` 전제 붕괴·이벤트 충격 → 개장 즉시 청산
  - [ ] `NO_TRADE` 전날 미진입 → 관망
- [ ] 위험 등급 신규진입 차단은 유지하되, **이미 보유분엔 위 4상태로 구체 실행** 부여
- 매핑: `run_preopen` 이 상태 산출(overnight 배수 + 확정 컨펌 + 게이트), renderer 상태 카드.

## 5. OPEN_EXIT_OR_HOLD — 개장 후 청산 규칙 🟡 [M·데이터 있음, A/B는 표본]
평가: 보유 시간 제한. 단순 규칙부터.
- [ ] **기준 전략**: 전날 종가 진입 → **다음날 09:05 청산**(단순, 먼저 측정)
- [ ] 청산 템플릿 A/B(이후): `Open Exit`(시가/지정분 무조건) · `Opening Range`(첫 5~15분 고저 이탈) · `Time Stop`(09:30/10:00 미확인 시)
- [ ] 개장/09:05/09:15 데이터 = **LS 분봉(t8412)** 으로 취득 가능
- 매핑: 청산 규칙 엔진(신규), LS 분봉, paper 체결.

## 6. POST_TRADE_REVIEW — 실현 성과 검증 🟡 [M·paper/표본]
평가: 확률이 아니라 **순기대값**과 비용포함 성적표.
- [ ] **순기대값** `E = P(win)·AvgWin − P(loss)·AvgLoss − Cost`
  - Cost = ETF 수수료 + 세금 + 양방향 스프레드 + 예상 슬리피지 + **갭 시 손절 미체결 위험**
  - 현재 `edge`(방향확률=승률 가정)는 실행 edge 로 쓰지 말 것 — 이미 고지됨
- [ ] **성적표(store 확장)**: 종가 주문 제출시각·실제 체결가·종가 대비 괴리 · 익일 시가/09:05/09:15/종가 수익률 · **MFE/MAE** · 비용차감 순수익 · 잠정↔확정 동일일 성과 · 야간컨펌(유지/약화/반전)별 성과 · `HOLD_FULL/REDUCE/EXIT_OPEN`별 성과 · **최대 연속손실·MDD**
- 매핑: `src/store.py` 성적표 스키마, 성과 뷰(evaluation2 P0-5 와 통합).
