## 0. 현실적 결론 먼저 (얼마나 갈 수 있나)

| 목표 | 도달 가능? | 제약 |
|---|---|---|
| **내부 의사결정 시스템 9급** | ✅ 도달 가능 | P0 전부 + P1 부분 + P2 부분. 대부분 **코드로 지금 가능** |
| **확률 검증 수치(Brier·calibration)가 "의미 있는" 수준** | 🟡 시간 게이트 | 코드는 지금 가능하나 **표본 250거래일+ 축적**이 필요 → 수개월 |
| **실행 가능 자동매매 10급** | 🔴 부분/보류 | Paper trading(L1)까지 가능. **실주문(L2~L4)은 고위험·별도 프로젝트** |

**가장 빠른 신뢰도 상승 2가지 (평가 최종 권고 = 우리 P0-1, P0-5):**
1. `데이터 완전성 100%` → **4개 품질지표로 분해**
2. `77%` 확률에 대한 **일별 검증 로그 축적 + 성과 페이지**

이 둘만 끝내도 객관성·신뢰도가 현재 수준에서 가장 크게 오른다. → **여기부터 착수.**

솔로·API 운영에 맞춘 판단:
- **PostgreSQL/Supabase 불필요** — 기존 SQLite(`src/store.py`)로 충분. 스냅샷·검증 로그 모두 SQLite.
- **실주문 자동화는 범위 밖** — LS 주문 TR + 실자금 리스크. L0(리포트)→L1(paper)까지만.
- 계산 엔진은 이미 순수함수(`scoring`/`atr`/`quant`/`overnight`)라 재현성·테스트에 유리.

가능성 범례: ✅ 완료 · 🟢 지금 코드로 가능 · 🟡 부분/시간·데이터 필요 · 🔴 보류(범위 밖·고위험)
